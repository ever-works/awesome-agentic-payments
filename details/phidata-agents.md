## Overview

Phidata is a multi-modal agent framework that supports x402 integration, allowing developers to build AI agents capable of making and receiving payments through the x402 protocol.

## Features

- Multi-modal agent development
- x402 payment integration
- Open source on GitHub
- Agent memory, knowledge, and tool use

## Pricing

Free and open source under an OSI-approved license.

## Deployment

Self-hosted or cloud-deployable.
