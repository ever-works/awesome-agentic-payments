## Overview

Nano Banana x402 is a paid Gemini image generation API that wraps gemini-3.1-flash-image-preview with x402 micropayments on Base mainnet.

## Features

- Generate images from prompt
- Edit existing images
- Returns base64 PNG
- Supports 10 aspect ratios
- x402 micropayments

## Pricing

$0.02 USDC per call on Base mainnet.

## Deployment

Cloud-hosted API. Source: https://github.com/bshelby88/nanobanana-x402
