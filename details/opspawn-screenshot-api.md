## Overview

OpSpawn Screenshot API is a pay-per-request screenshot and document generation API that accepts x402 micropayments. It provides screenshot capture and markdown conversion services for AI agents.

## Features

- Pay-per-request screenshot and document generation API
- x402 micropayments
- $0.01 per screenshot
- $0.005 per markdown conversion
- USDC on Base
- Open source on GitHub

## Pricing

- $0.01 per screenshot
- $0.005 per markdown conversion
