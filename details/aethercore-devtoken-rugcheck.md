## Overview

AetherCore-Dev/token-rugcheck provides Solana token safety auditing for AI agents via the Model Context Protocol.

## Features

- Solana token safety audit
- Three-layer risk analysis: machine verdict + LLM analysis + raw on-chain evidence
- Data from RugCheck.xyz, DexScreener, and GoPlus Security
- Live on mainnet
- USDC micropayments ($0.02/audit) via x402 protocol
- Available on Glama MCP registry

## Pricing

$0.02 per audit (USDC via x402).

## Deployment

MCP server (available on Glama).
