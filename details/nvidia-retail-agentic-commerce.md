## Overview

NVIDIA Retail Agentic Commerce is a reference architecture from NVIDIA AI Blueprints for building agentic commerce applications. Supports ACP and UCP protocols.

## Features

- Reference architecture for retail agentic commerce
- Supports ACP and UCP protocols
- Python implementation
- Official NVIDIA project

## Specification

- Language: Python
- Maintainer: NVIDIA (official)
