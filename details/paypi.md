## Overview

paypi is a Solana intelligence service for AI agents, offering pay-per-call data APIs that settle in USDC on Solana and Base via the Coinbase CDP facilitator.

## Features

- Solana transaction decode: $0.005 USDC
- Transaction simulation: $0.005 USDC
- Kamino liquidation-risk intelligence: $0.05 USDC
- x402 v2 with Bazaar discovery
- No API keys, no signup
- No accounts required

## Integrations

- x402 discovery at `.well-known/x402`
- MCP manifest available
- Settles via Coinbase CDP facilitator
