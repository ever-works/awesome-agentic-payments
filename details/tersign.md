## Overview

Tersign is a neutral evidence layer for x402 agent commerce.

## Features

- Seller-signed EIP-712 receipts
- Agent action records
- Counter-signed into per-seller hash chains on a public ledger
- Verifiable by anyone without an account
- Refunds
- Deterministic dispute triage
- Exportable evidence packs for audits and disputes
- One-line verification: `npx tersign verify --ledger https://tersign.ai`

## Pricing

Open source; verification via npx.

## Deployment

Cloud-hosted at tersign.ai
