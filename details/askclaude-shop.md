## Overview

AskClaude is a pay-per-query Claude AI API that provides access to multiple Claude models and specialized tools via x402 micropayments on Base. It supports streaming and includes an MCP server for agent integration.

## Features

- Pay-per-query Claude AI API
- 9 endpoints: Haiku ($0.01), Sonnet ($0.03), Opus ($0.10)
- Specialized tools: summarization, code review, translation, sentiment analysis, crypto analysis
- Streaming support
- USDC on Base
- MCP Server available on npm
- Open source on GitHub

## Pricing

- Haiku: $0.01 USDC per query
- Sonnet: $0.03 USDC per query
- Opus: $0.10 USDC per query
