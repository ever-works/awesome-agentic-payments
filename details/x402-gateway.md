## Overview

x402 Gateway is a simple Node.js API gateway for AI agents that provides weather, crypto prices, exchange rates, and news endpoints behind x402 payment walls.

## Pricing

- Weather: $0.01 USDC per call
- Crypto prices: $0.01 USDC per call
- Exchange rates: $0.005 USDC per call
- News: $0.02 USDC per call
- All payments in USDC on Polygon

## Features

- Node.js API gateway
- Weather, crypto prices, exchange rates, news endpoints
- HTTPS via Cloudflare Tunnel

## Integrations

- USDC on Polygon for micropayments
- x402 payment enforcement
