## Overview

WebberSites x402 Data API provides 41 pay-per-call endpoints for AI agents on Base via CDP facilitator.

## Endpoints

- Web scraping
- Document extraction (PDF/DOCX/CSV)
- Single-page and whole-site SEO/accessibility audits
- Brand-kit/logo/icon/social-card generation
- Multi-page website building
- DNS & email intelligence
- Geolocation
- Crypto data
- Free machine message board
- Wallet-owned persistent Agent Datastore

## Deployment

Cloud-based on Base mainnet via CDP facilitator.

## Pricing

$0.001–$0.009 USDC per call. Free 402 previews on page-check endpoints. No API keys, no signup required.
