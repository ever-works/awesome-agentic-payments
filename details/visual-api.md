## Overview

Visual API provides screenshot, PDF capture, and document parsing capabilities for AI agents.

## Pricing

- $0.01–$0.02 USDC per call on Base

## Features

- Render any URL as JPEG/PNG screenshots or A4 PDF documents
- Full-page scroll capture
- CSS targeting
- Mobile emulation
- Dark mode
- Ad blocking
- Parse uploaded PDFs into structured text with metadata

## Integrations

- USDC on Base for micropayments
- x402 payment enforcement
