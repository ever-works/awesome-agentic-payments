## Overview

DJD AgentScore is an on-chain reputation scoring API for AI agent wallets. It returns a 0-100 trust score across 5 dimensions based on x402 settlement history on Base.

## Features

- On-chain reputation scoring API for AI agent wallets
- 0–100 trust score
- 5 dimensions: identity, behavior, reliability, viability, capability
- Based on x402 settlement history on Base
- Free tier
- No signup required
- Open source on GitHub
