## Overview

Intelligence Aeternum is a monetized MCP server marketplace featuring museum artwork data with x402 micropayment support.

## Features

- First monetized MCP server marketplace
- 2M+ museum artworks
- x402 USDC micropayments on Base L2
- 16 MCP tools for search, enrichment, and delivery
- Live endpoint: https://data-portal-172867820131.us-west1.run.app/mcp
