## Overview

SkillMint is a pay-per-call AI skills marketplace with 51 skills across 7 categories including dev tools, creative design, research, writing, and docs. No API keys or subscriptions are required.

## Features

- 51 skills across 7 categories
- Dev tools, creative design, research, writing, docs
- Pay-per-call pricing
- No API keys
- No subscriptions
- x402 micropayments on Base

## Pricing

$0.01–$0.50 USDC per call on Base.
