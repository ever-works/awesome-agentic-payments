## Overview

dTelecom STT is a real-time speech-to-text API built on dTelecom DePIN infrastructure. It uses a dual-engine architecture combining Parakeet-TDT and Whisper models, supporting 99+ languages with hallucination filtering.

## Features

- Real-time speech-to-text API
- Dual-engine architecture: Parakeet-TDT + Whisper
- 99+ languages supported
- Hallucination filtering
- $0.005/min pricing
- Built on dTelecom DePIN
- Python SDK available
- TypeScript SDK available
- Open source on GitHub
