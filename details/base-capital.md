## Overview

Base Capital is an autonomous x402 on-chain risk-intelligence API for AI trading agents on Base, providing token risk scores and risk-ranked trending signals.

## Features

- Token risk scores at $0.01 USDC/call
- Risk-ranked trending signals
- On-chain RiskStake reputation contract
- ERC-8004 agent identity
- Optimistic dispute resolution with bonded challenges
- Builder-code attribution
- No API keys, no accounts

## Pricing

- $0.01 USDC per call

## Deployment

Cloud-hosted on Base mainnet via x402 payment rail.
