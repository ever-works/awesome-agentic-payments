## Overview

Bloomfilter is an x402-powered domain registration API for AI agents. It enables registration of ICANN domains and DNS management with payment via USDC on Base.

## Features

- x402-powered domain registration API
- Register ICANN domains
- Manage DNS
- Pay with USDC on Base

## Pricing

- Pay-per-use via x402 USDC

## Deployment

Cloud-hosted at bloomfilter.xyz

## Integrations

- x402 payment protocol
- Base mainnet USDC
