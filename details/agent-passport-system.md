## Overview

Agent Passport System (APS) is an open-source governance and delegation layer for x402 payments.

## Features

- Cryptographic agent identity
- Scoped delegation with spending caps
- Rotation-aware DID verification
- Signed receipts with per-condition attestation

## Pricing

Open source, free to use.
