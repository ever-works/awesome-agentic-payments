## Overview

ATXP is an agent identity and funding platform designed for AI agents. One command (`npx atxp agent register`) provisions an agent with a USDC wallet on Base, an @atxp.email inbox, a phone number, and access to 100+ paid tools including web search, image/video generation, and LLM gateway.

## Features

- USDC wallet on Base L2
- @atxp.email inbox for agent communication
- Phone number provisioning
- 100+ paid tools (web search, image/video generation, LLM gateway)
- x402-compatible — agents can pay x402 endpoints directly from ATXP balance
- $5 free credit, no KYC required

## Pricing

$5 free credit for new agents. Usage beyond the free credit is paid. Open source on GitHub.

## Deployment

Cloud-hosted platform with self-hostable open-source components.
