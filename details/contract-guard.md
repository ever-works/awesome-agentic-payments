## Overview

contract-guard provides risk checks for EVM contracts and token addresses, identifying proxy/upgradeability issues, ERC-20 traps, and ownership flags across multiple chains.

## Pricing

- $0.005 USDC per call on Base

## Features

- Proxy and upgradeability detection
- ERC-20 trap detection
- Ownership flag detection
- Supports Base, Ethereum, Arbitrum, Optimism, Polygon, and BSC
- No signup required

## Integrations

- USDC on Base for micropayments
- x402 payment enforcement
