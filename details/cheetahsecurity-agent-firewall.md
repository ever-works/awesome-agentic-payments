## Overview

cheetahsecurity Agent Firewall is a prompt-injection/jailbreak firewall for AI agents.

## Features

- POST untrusted inbound text (post/comment/DM, tool output, web content) to /scan
- Returns safe/blocked verdict
- Self-hosted detection (LLM Guard / DeBERTa)
- MIT license
- No third-party data sharing
- $0.01 USDC per scan on Base
