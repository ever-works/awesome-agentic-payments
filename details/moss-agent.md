## Overview

MOSS Agent provides AI-powered coding services for agents via x402 micropayments on Base. It offers code review, translation, and explanation services with A2A protocol compatibility.

## Features

- AI-powered coding services
- Code review: $0.005
- Translation: $0.003
- Code explanation: $0.003
- x402 micropayments on Base
- A2A protocol compatible
- Agent discovery at /.well-known/agent.json
- Built with Lucid Agents + Hono

## Pricing

- Code review: $0.005 USDC
- Translation: $0.003 USDC
- Code explanation: $0.003 USDC
