# GATEWAY

## Overview
Canonical Algorand x402 discovery router.

## Features
- Exact AVM
- Dual-accept testnet+mainnet
- Free cleaned `/registry`
- Paid `/discover` / `/probe` / `/batch` / `/diff`
- GoPlausible facilitator
- MCP support
- `agents.txt` / `llms.txt` / Agentverse
- Challenge tag: `x402-global-challenge`

## Pricing
Free registry; paid discovery endpoints.

## Deployment
Hosted service on Vercel.
