## Overview

PYTHIA Oracle is an Oracle MCP server providing AI agents with oracle consultation capabilities.

## Features

- One tool: consult_oracle
- One reading per call
- 3 free readings per agent
- Then $0.025 USDC on Base via x402
- Available on Smithery and Glama

## Pricing

3 free per agent, then $0.025 USDC on Base via x402.

## Deployment

MCP server (available on Smithery and Glama).
