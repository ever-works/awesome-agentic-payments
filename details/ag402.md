## Overview

ag402 is a payment layer for AI agents built on x402. It allows developers to wrap any API or MCP server with a USDC paywall, or enable agents to auto-pay for services. It runs on Solana USDC with sub-second settlement and is non-custodial.

## Features

- Wrap any API or MCP server with a USDC paywall (ag402 serve)
- Let agents auto-pay (ag402 run)
- Solana USDC settlement (~0.5s)
- Non-custodial
- Compatible with Claude Code, Cursor, LangChain, AutoGen
- token-rugcheck MCP integration
- Glama MCP server integration
- Open source on GitHub

## Pricing

- Open source, free to use
- USDC micropayments on Solana
