# MoltsPay Python

## Overview
Python SDK for x402 agent payments.

## Features
- LangChain compatible
- Auto-creates wallets
- Discovers services
- Pays via x402
- Multi-chain: Base, Polygon, Solana, BNB

## Pricing
Free and open source.

## Deployment
Client-side Python SDK.
