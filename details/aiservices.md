## Overview

AIServices provides a 16-endpoint crypto and market intelligence API for AI agents via x402 USDC micropayments on Base.

## Free Endpoints

- Prices
- Trending
- Global market cap
- Gas tracker
- Predictions
- News
- Social sentiment
- Swap quotes

## Paid Endpoints (via x402)

- Search ($0.01)
- Technical indicators ($0.02)
- DeFi yields ($0.02)
- URL metadata ($0.01)

## Deployment

Cloud-based on Base mainnet via Coinbase CDP facilitator.

## Pricing

USDC on Base. No API keys for free endpoints, no signup required.
