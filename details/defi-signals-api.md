## Overview

DeFi Signals API provides cross-venue perpetual funding rates and DeFi market data for AI agents.

## Pricing

- $0.002–$0.01 USDC per call on Base

## Features

- Cross-venue perpetual funding rates (OKX, Kraken Futures, dYdX)
- Arbitrage spread signal
- Outlier-cleaned DeFi yields
- BTC/ETH/SOL market snapshots
- Fear & Greed index
- 3 endpoints

## Integrations

- USDC on Base for micropayments
- x402 payment enforcement
