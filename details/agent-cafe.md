## Overview

Agent Cafe is a live mainnet endpoint that tests and certifies x402 agents by grading the client side rather than the seller side.

## Features

- Live mainnet endpoint
- Pays real USDC on Base
- Public certificate issued
- README badge of agent capabilities
- Scam-resistance test (refusal of over-priced orders)
- Free machine-readable menu at /inspect
- Grades the client, not the seller

## Pricing

Real USDC on Base payments during testing.

## Deployment

Cloud-hosted API. Examples: https://github.com/englishdoggy/agentcafe-examples
