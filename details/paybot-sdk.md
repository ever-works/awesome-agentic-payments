# PayBot SDK

## Overview
TypeScript SDK for integrating x402 payments into AI agents and bots.

## Features
- Automatic 402 detection
- Wallet management
- USDC payments on Base

## Pricing
Free and open source.

## Deployment
Client-side SDK, no server deployment required.

## Integrations
- npm package: `paybot-sdk`
- GitHub: https://github.com/RBKunnela/paybot-sdk
