## Overview

JarvisClaw Agent Gateway is an OpenAI-compatible LLM gateway where AI agents pay per-token via x402 on Base.

## Features

- OpenAI-compatible LLM gateway
- Per-token payment via x402 on Base
- Semantic intent resolver for natural language requests
- Optimal model routing with budget validation
- Supports 200+ models
- Automatic fallback across providers
- MCP tool discovery
- No signup, no quota
- Wallet pays directly

## Pricing

Per-token via x402 on Base.

## Deployment

API hosted at api.jarvisclaw.ai; docs at docs.jarvisclaw.ai
