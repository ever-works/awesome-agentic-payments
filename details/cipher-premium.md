## Overview

CIPHER Premium is a Next.js 16 paywall application that gates access to Solana-quant content chapters. It charges per-fetch via x402 on Base.

## Features

- Next.js 16 paywall
- 4 gated Solana-quant chapters: MEV deep-dive, 3-tier wallet, Canadian compliance, Oracle Cloud Always Free
- $0.25 USDC/Base per fetch
- Hand-rolled proxy.ts
- No facilitator dependencies at advertise time

## Pricing

- $0.25 USDC/Base per fetch via x402

## Deployment

Cloud-hosted (Vercel)
