## Overview

Trusted Agentic Commerce Protocol (TACP) is a trust-signal overlay protocol from Forter. It operates orthogonally to cart/checkout protocols, providing agent trust signals alongside ACP, UCP, and AP2.

## Features

- Parallel agent-trust overlay (orthogonal to cart/checkout)
- JWKS endpoint for key publication only (no capability discovery)
- Payment auth: n/a (signal layer)
- Signed requests: JWS + JWE
