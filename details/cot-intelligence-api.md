## Overview

COT Intelligence API delivers CFTC Commitments of Traders data for FX trading agents, including weekly futures positioning and z-score analysis.

## Pricing

- $0.01–$0.02 USDC per call on Base

## Features

- Weekly futures positioning for JPY, EUR, GBP, CHF, CAD, AUD
- Z-score analysis
- Positioning extremes detection
- Yield-momentum cross signals
- 26-week z-score history

## Integrations

- USDC on Base for micropayments
- x402 payment enforcement
