## Overview

MoltPe is an AI-native payment infrastructure MCP server for autonomous USDC payments.

## Features

- 11 MCP tools for autonomous USDC payments
- Non-custodial agent wallets
- Shamir key splitting
- Programmable spending policies (daily caps, per-tx caps, allowlists)
- Tri-rail support: x402 (HTTP-native), MPP (session-based), fiat
- Sub-second settlement on Polygon PoS, Base, and Tempo
- Free tier
- No credit card required
- Site: https://moltpe.com
