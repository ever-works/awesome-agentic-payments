## Overview

SEC Reg CF Raise Tracker tracks US Regulation Crowdfunding (Form C) startup raises for AI agents.

## Features

- Query live and historical offerings by issuer CIK, industry (SIC), state, security type, minimum size, or recency
- Returns parsed deal terms (amount sought, max, raised-so-far, deadline, funding portal, issuer financials)
- Honest open/closed/unknown statuses and index-freshness metadata
- 1,200+ offerings indexed from SEC EDGAR (public domain)
