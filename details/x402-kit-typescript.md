## Overview

x402-kit is a MIT-licensed Express middleware and slug-routed multi-tenant data plane that powers x402-saas. It includes 38 tests with a real x402.rs facilitator wired in.

## Key Features

- MIT-licensed Express middleware
- Slug-routed multi-tenant data plane
- Powers x402-saas hosted onboarding proxy
- 38 tests with real x402.rs facilitator wired in

## Deployment

Self-hostable from GitHub repository.
