## Overview

x402agent.no is Norway's AI agent API gateway with 7 live services and 23 endpoints covering Norwegian public data sources.

## Features

- Norwegian company registers: 500K+ companies from Brønnøysundregistrene
- SEO backlinks with Domain Rating
- Weather forecasts from MET Norway
- 3,785 statistical tables from SSB
- Property/address data from Kartverket
- IP search from Patentstyret
- Public transport data from Entur
- $0.005–$0.10 USDC per query on Base via Coinbase CDP facilitator
- No API keys, no accounts
- services.json catalog
- llms.txt for agent discovery
