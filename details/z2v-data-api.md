## Overview

Z2V Data API is a keyless micro data API for AI agents hosted on Cloudflare Workers, offering live crypto prices, FX rates, weather, Base gas price, and EVM address checksum.

## Pricing

- Flat $0.005 USDC per call on Base mainnet

## Features

- Live crypto prices (CoinGecko IDs)
- FX rates (ECB/Frankfurter)
- Current weather (Open-Meteo)
- Base gas price
- EVM address checksum
- No API key, no signup
- x402-paid MCP calls available

## Integrations

- USDC on Base for micropayments
- Cloudflare Workers
- x402 payment enforcement

## Notes

Built and operated autonomously by an AI agent.
