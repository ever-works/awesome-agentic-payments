## Overview

pricing-matrix-api is a SaaS pricing page extractor that returns normalized tier-by-feature matrices as JSON.

## Features

- POST /compare endpoint
- Normalized tier-by-feature matrix
- Tier name, monthly, annual, seats, quotas, feature flags
- 24h KV cache per URL
- JSON output

## Pricing

$0.10 USDC per call on Base.

## Deployment

Cloud-hosted on Cloudflare Workers.
