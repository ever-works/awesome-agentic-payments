## Overview

DocForge provides machine-payable document and media generation for AI agents via x402 on Base.

## Features

- Markdown/HTML to PDF and DOCX conversion
- Structured data to PDF invoices
- Charts generation
- Excel workbooks
- PowerPoint decks
- Mermaid/Graphviz diagrams
- Screenshots
- Multi-document ZIP bundles
- OpenAPI 3.1 specification
- Bazaar discovery

## Pricing

- $0.01–$0.10 USDC per call on Base

## Deployment

Cloud-hosted API service.

## Integrations

- Base network
- USDC
- x402 payment protocol
- OpenAPI 3.1
- Bazaar discovery
