## Overview

Intel API provides AI-synthesized token due diligence reports for crypto assets by aggregating GoPlus security checks and CoinGecko market data.

## Pricing

- $0.50 USDC per call on Base

## Features

- Aggregates 4 GoPlus security checks
- CoinGecko market data integration
- Risk-scored verdicts with red/green flags
- Recommendations
- Replaces 5+ separate security APIs in one call

## Integrations

- USDC on Base for micropayments
- x402 payment enforcement
- GoPlus Security
- CoinGecko
