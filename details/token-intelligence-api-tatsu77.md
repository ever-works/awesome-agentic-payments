## Overview

Token Intelligence API provides EVM token security analysis with deterministic risk scoring and natural language summaries. It aggregates GoPlus contract, holder, and liquidity data in a single request via x402 micropayments.

## Features

- EVM token security analysis
- Deterministic risk scoring
- Natural language summaries
- x402 micropayments
- Aggregates GoPlus contract, holder, and liquidity data in one request
- Batch endpoint: up to 10 tokens ($0.020)
- $0.01 USDC on Base
- Open source on GitHub
- llms.txt available

## Pricing

- $0.01 USDC per call on Base
- Batch endpoint (up to 10 tokens): $0.020 USDC
