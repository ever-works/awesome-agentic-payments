## Overview

Product Reputation API is an AI-powered product reputation intelligence service that aggregates data from Reddit, Hacker News, and YouTube. It is open source and accessible via x402 micropayments.

## Features

- Structured reputation scores
- Dimensional analysis
- Competitor comparisons
- Data from Reddit, HN & YouTube
- x402 pay-per-query

## Pricing

$0.03-$0.08 USDC per query.
