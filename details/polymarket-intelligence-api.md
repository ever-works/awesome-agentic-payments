## Overview

Polymarket Intelligence API provides prediction market anomaly signals for AI agents using z-score detection on Polymarket odds.

## Pricing

- $0.01 USDC per call on Base

## Features

- Z-score detection on Polymarket odds
- Surfaces events where odds moved 2+ standard deviations from rolling mean
- Covers fed rates, crypto prices, regulation, geopolitics, tariffs

## Integrations

- USDC on Base for micropayments
- x402 payment enforcement
