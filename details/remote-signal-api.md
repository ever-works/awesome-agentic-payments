## Overview

Remote Signal API is a curated JSON feed API that aggregates 50 RemoteOK dev/SaaS jobs and 20 Hacker News Show HN posts, designed for recruiting teams and indie builders.

## Pricing

- Free tier: 10 requests per day
- $5/month API key via USDC on Base
- $0.02 USDC per request via x402 for agents

## Features

- Curated JSON feed of remote jobs and Show HN posts
- x402-gated access with wallet-as-auth
- No signup required for x402 access

## Integrations

- USDC on Base for micropayments
- RemoteOK job feed
- Hacker News Show HN feed
