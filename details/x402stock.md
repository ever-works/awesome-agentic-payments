## Overview

x402stock is a real-time US stock market data API for AI agents with 23 pay-per-call endpoints accessible via x402 on Base.

## Features

- 23 pay-per-call endpoints
- Quotes
- Snapshots
- OHLC aggregates
- Company fundamentals
- Dividends
- Splits
- Corporate events
- Market news
- Top gainers/losers
- Whole-market grouped daily
- Technical indicators: SMA, EMA, RSI, MACD
- No API keys, no accounts

## Pricing

$0.01-$0.03 USDC per call on Base via x402.

## Deployment

Cloud-hosted API.
