## Overview

Chainfacts provides verifiable token risk / pre-trade rug screens for any Base ERC-20.

## Features

- Deterministic contract-security facts (upgradeable proxy / EIP-1967, ownership renounced, mint authority, paused)
- Holder concentration metrics (Gini, HHI, Nakamoto, top-1/3/5/10 share)
- 0-100 risk score
- Block-pinned with reproducible sha256 attestation
- Independently recomputable by any agent
- 3 pay-per-call routes
- USDC on Base
- No API key required
