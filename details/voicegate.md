## Overview

VoiceGate is a voice/telephony layer for autonomous agents that enables PSTN phone calls with x402 USDC payments.

## Features

- Agent places real PSTN phone calls
- Pay per minute in USDC over x402
- No card, no human in billing loop
- Model-agnostic (bring your own LLM via webhook)
- Agent authenticates with verifiable credential (KYA, aligned with ERC-8004)
- Open-source MIT SDK for Python and Node
- Hosted call API in private beta

## Pricing

Per-minute USDC payment over x402.

## Deployment

Hosted API at aivoicegate.com; SDKs on GitHub, PyPI, and npm
