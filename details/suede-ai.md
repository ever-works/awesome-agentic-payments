## Overview

Suede is an x402-paid AI music and video generation API for AI agents. It offers music and video generation endpoints with x402 payment requirements, and includes ACP-ready commerce intent support.

## Features

- x402-paid AI music and video generation API
- /agent/generate: music generation ($0.75 USDC)
- /create-music: music generation ($0.75 USDC)
- /agent/video: short video generation ($5.00 USDC)
- Returns live 402 Payment Required with x402 payment requirements
- Discovery via /.well-known/x402, /.well-known/x402.json, /.well-known/agent-card.json
- USDC on Base
- ACP-ready commerce intent endpoint at /agents/commerce
- Open source on GitHub

## Pricing

- /agent/generate: $0.75 USDC
- /create-music: $0.75 USDC
- /agent/video: $5.00 USDC
