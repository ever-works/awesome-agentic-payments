## Overview

PortsideLabs KoinChappie is a crypto signals API that returns bull and bear signals for top cryptocurrencies using SMA(14) across multiple timeframes.

## Pricing

- $0.001 USDC per call

## Features

- Bull and bear signals for top 10 cryptocurrencies by market cap
- 8 timeframes (1m–1D)
- SMA(14) based signals
- Single-coin lookup supports any CryptoCompare symbol

## Integrations

- USDC on Base mainnet and Solana mainnet for micropayments
- x402 payment enforcement
