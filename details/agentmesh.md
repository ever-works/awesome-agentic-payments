## Overview

AgentMesh is a crypto data API with 3-tier referral commissions for AI agents, using x402 for payments.

## Features

- 5 endpoints: token-price, dex-price, klines, wallet-score, gas-estimate
- $0.01 per call via x402
- MCP server enabled
- 3-tier referral commissions
- Agents earn 10-20% commission when referrals use the API

## Pricing

$0.01 per call via x402.
