## Overview

ShadowQuant Intelligence provides validated equities/options market research for AI agents via x402 USDC micropayments on Base.

## Features

- Volatility regime (VIX term structure, cross-asset ratios)
- Options IV
- Seasonal bias with FDR-adjusted significance
- Granger lead-lag map
- Correlation regime
- Market context
- Every response embeds provenance — generation timestamp, honest staleness flag, methodology, and a publicly graded track record

## Deployment

Cloud-based on Base mainnet via x402.

## Pricing

$0.005–$0.02 USDC per call. No API keys, no signup required. Research data, not investment advice.
