## Overview

true402 MCP is a machine-native x402 marketplace on Base offering token safety and market intelligence tools.

## Features

- Token rug check with real buy/sell honeypot simulation (proves sellability, not just static flags)
- Address safety
- Deployer reputation
- New pairs
- Whale swaps
- SEO/GEO audits
- LLM inference
- ~13 tools
- $0.001–$0.015 USDC on Base
- First few safety checks free
- No wallet needed

## Pricing

- First few safety checks free
- $0.001–$0.015 USDC per call on Base
- Pay per call via x402

## Deployment

Cloud-hosted MCP server.
