## Overview

Micro Data API Factory — Weather is a Cloudflare Workers edge weather API for AI agents, delivering instant weather data by city name without API keys or geocoding setup.

## Pricing

- $0.001 USDC per call on Base

## Features

- Instant data by city name
- No API keys, no geocoding setup, no rate limits
- Current conditions + 1-7 day forecasts worldwide
- 402 body includes live upstream peek, free preview URL, and MCP gateway handle

## Integrations

- USDC on Base for micropayments
- x402 payment enforcement
- Open-Meteo (CC BY 4.0)
- Cloudflare Workers
- MCP gateway
