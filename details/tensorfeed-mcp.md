## Overview

TensorFeed MCP is an MCP server providing real-time AI industry intelligence for AI agents.

## Features

- 6 free tools: AI news from 15+ sources, service status, model pricing, today summary, agent activity
- 13 paid premium tools: routing recommendations, news search, history series, cost projection, provider deep-dive, model comparison, agents directory, what's new brief, webhook watches
- Daily/weekly digest tier
- Welcome bonus: 50 free credits on first wallet payment
- Pay-per-call in USDC on Base mainnet
- No accounts required
- Official MCP registry: ai.tensorfeed/mcp-server (DNS-verified tensorfeed.ai)
- Usage: `npx -y @tensorfeed/mcp-server`
- x402 V2 discovery at /.well-known/x402

## Pricing

$0.02 USDC per credit on Base, volume discounts at $5/$30/$200.

## Deployment

npm package (MCP server); docs at https://tensorfeed.ai/developers/agent-payments.
