## Overview

MiroShark is a universal swarm-intelligence engine exposed as a paid API via x402.

## Features

- POST a scenario to the `/x402/run` surface
- Hundreds of grounded LLM personas simulate Twitter, Reddit, and prediction markets hour-by-hour
- Returns an analytical report
- Settles in USDC on Base via x402

## Pricing

Paid via x402 USDC on Base.

## Deployment

Cloud-hosted API.

## Integrations

- x402 payment protocol
- Base network (USDC)
