## Overview

AgentIndex is a unified search platform that aggregates MCP services, A2A agents, and x402 APIs from 5 different registries. It offers free browsing and stats, with paid search, analyze, and trending endpoints via x402.

## Features

- Unified search across 15,000+ MCP services, A2A agents, and x402 APIs
- 5 registries: Smithery, official MCP, GitHub, Bazaar, A2A
- Free browse/stats endpoints
- x402 paid search: $0.005, analyze: $0.05, trending: $0.10
- USDC on Base
- Open source on GitHub
