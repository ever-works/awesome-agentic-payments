## Overview

Apexti Toolbelt provides access to 1,500+ Web3 APIs through x402 MCP servers, enabling AI agents to access blockchain and Web3 data via micropayments.

## Features

- 1,500+ Web3 APIs
- Access via x402 MCP servers
- Web3 data and infrastructure for AI agents
- x402 payment settlement

## Pricing

- Pay-per-call via x402 USDC

## Deployment

Cloud-hosted
