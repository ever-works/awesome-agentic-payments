## Overview

Watchtower provides deterministic sanctions & export-control name screening for AI agents.

## Features

- Screens people, companies, vessels, and crypto addresses
- Against OFAC (SDN + Consolidated), UN, EU, UK OFSI, Canada (SEMA), Australia (DFAT)
- US export-control lists (BIS Entity List, Denied Persons, State ITAR-Debarred/Nonproliferation)
- ~48,000 parties, refreshed daily
- Typo/alias/non-Latin-tolerant matching
- Every response carries snapshot hash + reproducible receipt for audit

## Pricing

- $0.02/name via x402 (USDC on Base), MCP, or API key
- No signup
