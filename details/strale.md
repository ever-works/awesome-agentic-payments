## Overview

Strale is a trust layer for AI agents providing 250+ business data and compliance capabilities via x402 micropayments. It offers quality-scored data with dual-profile reliability tracking and both MCP server and REST API access.

## Features

- 250+ independently tested business data and compliance capabilities
- x402 micropayments
- IBAN validation, VAT checks, sanctions screening
- Company data, SSL checks
- MCP server + REST API
- Quality-scored (SQS) with dual-profile reliability tracking
- $0.02–$1.00 USDC
