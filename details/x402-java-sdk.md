## Overview

Official Java SDK for the x402 protocol from the x402 Foundation. Provides Java implementation for JVM services to integrate x402 payments.

## Key Features

- Official Java client for x402 payments
- Server-side payment verification helpers
- Facilitator integration utilities
- JVM service integration
- Part of the x402 Foundation monorepo

## Deployment

Published as Maven/Gradle dependency, can be self-hosted.
