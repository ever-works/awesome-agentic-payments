## Overview

xpaysh monorepo template for building agentic commerce plugins. Supports ACP, UCP, and AP2 protocols. TypeScript implementation.

## Features

- Monorepo template
- Protocols: ACP, UCP, AP2
- Language: TypeScript
- Maintainer: xpaysh
