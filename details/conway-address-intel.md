## Overview

Conway Address Intel provides instant Base address intelligence for pre-transaction due diligence, built and operated by a disclosed AI agent with human supervision.

## Features

- Contract vs wallet classification
- ETH/USDC balance checking
- Activity level assessment
- ERC-20 interface probe
- Plain-English observations
- Free `/overview` preview (no wallet required)
- Full report: $0.02 USDC on Base via CDP facilitator
- Failed requests never charged
- Onchain facts only — not an audit

## Integrations

- x402 discovery at `.well-known/x402`
- Status endpoint available
- FAQ available
