## Overview

mondello.dev is Romy Mondello's blog on agent-era patterns covering x402 endpoint design, agent-discoverable surfaces, and consulting funnels for agent-native sites.

## Features

- x402 endpoint design
- Agent-discoverable surfaces (llms.txt, OpenAPI 3.1 with x-x402-payment extensions, MCP)
- Consulting funnels for agent-native sites
- Worked examples with posts
- Site runs 9 paid x402 endpoints on Base mainnet
- 16-tool MCP server

## Pricing

Paid x402 endpoints on Base mainnet.

## Deployment

Cloud-hosted at mondello.dev
