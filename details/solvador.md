# Solvador

## Overview
Multi-network, multi-scheme x402 facilitator.

## Features
- 10 EVM chains: Base, Arbitrum, Optimism, Polygon, Avalanche, Celo, Linea, Unichain, World Chain, Monad
- Solana mainnet support
- NEAR mainnet support
- Supports `exact` scheme
- Supports `upto` (Permit2) scheme
- Supports `batch-settlement` scheme
- Settled-transaction dashboard
- API keys
