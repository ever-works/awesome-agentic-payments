# agent402-tollbooth

## Overview
Pay-per-crawl gate for site owners.

## Features
- Two-line Express/Next/Cloudflare integration
- Bot-only / all-traffic / strict charge modes
- Adaptive proof-of-work fallback for low-trust requests
- Per-route pricing in USDC on Base via x402
- `gate.stats()` API
- `/__tollbooth` analytics dashboard
- Deploy templates: Cloudflare Workers, Next.js middleware, Docker
- Drop-in, no rewrite required
- Managed service: Tollbooth Cloud
- WordPress plugin available

## Pricing
Per-route pricing in USDC on Base.

## Deployment
Server-side middleware.
