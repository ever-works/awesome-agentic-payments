## Overview

Coinnect is a non-profit, open-source money transfer routing API that helps AI agents find the cheapest multi-hop payment paths across 45+ live data sources. It settles via x402 USDC on Base L2.

## Features

- x402-payable money transfer routing API
- $0.002 USDC per query on Base L2
- Finds cheapest multi-hop paths across 45+ live data sources
- Sources: crypto exchanges, remittance providers, P2P markets
- REST API + MCP tools for AI agents
- Non-profit, MIT licensed
- Open source on GitHub
- Agent discovery via .well-known/agent.json
