## Overview

Mart402 provides web and PDF extraction APIs for AI agents with hallucination-guarded OCR, featuring dual-engine consensus and Japanese-strong capabilities.

## Features

- Dual-engine consensus (VLM + traditional OCR)
- Calibrated confidence scoring
- Honest disagree verdicts
- Japanese-strong OCR
- Invoice verification
- Schema-driven extraction
- JP company profiles
- $0.001-$0.02 USDC per call on Base via x402 (CDP facilitator)
- Free identical sandbox on Base Sepolia
- Measured latency and success stats published
