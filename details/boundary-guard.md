## Overview

Boundary Guard is a pre-action checkpoint API for agents that returns allow, retry, or block with a deterministic receipt before downstream actions.

## Features

- Returns allow, retry, or block plus deterministic receipt
- Pre-action checkpoint before downstream writes, sends, or other actions
- Live docs and x402 inventory published on public host
