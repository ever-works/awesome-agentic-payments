# Azeth SDK

## Overview
TypeScript SDK for x402 payments with smart accounts and service discovery.

## Features
- x402 client (`fetch402`)
- ERC-4337 smart accounts
- On-chain reputation feedback after every x402 call
- ERC-8004 service discovery
- USDC on Base

## Pricing
Free and open source.

## Deployment
Client-side SDK, no server deployment required.

## Integrations
- npm package: `@azeth/sdk`
- GitHub: https://github.com/azeth-protocol/sdk
