## Overview

FDA Intelligence API delivers OpenFDA drug and device safety intelligence for AI agents through 4 endpoints.

## Pricing

- $0.01 USDC per call on Base

## Features

- Drug adverse event aggregation with severity/outcome stats
- Label key section extraction
- Drug and device recall classification (Class I/II/III)
- 4 endpoints

## Integrations

- USDC on Base for micropayments
- x402 payment enforcement
