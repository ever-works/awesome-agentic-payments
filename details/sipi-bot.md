## Overview

sipi.bot is a pre-spend firewall for autonomous AI agents that enforces spending policies before payments are made.

## Features

- One call before payment returns APPROVED, BLOCKED, or FLAGGED
- Per-transaction caps
- Daily totals enforcement
- Velocity limits (runaway-loop protection)
- Merchant allow/block lists
- Category rules
- Time windows
- Human-in-the-loop approval queue
- Tamper-evident audit log
- Rail-agnostic: governs x402, AP2, and AgentKit payments
- MCP + HTTP + CLI interfaces
- Open-source core (MIT)
- Free to self-host
