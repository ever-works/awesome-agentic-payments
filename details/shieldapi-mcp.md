## Overview

ShieldAPI MCP is a 9-tool security MCP server that provides password breach, email breach, domain reputation, IP reputation, URL safety, full security scan, prompt injection detection, and skill security scanning capabilities.

## Pricing

- x402 USDC micropayments on Base
- Free demo mode available

## Features

- 9 security tools: password breach, email breach, domain reputation, IP reputation, URL safety, full security scan, prompt injection detection, skill security scanning
- x402 USDC micropayments on Base
- Free demo mode
- Installable via npx shieldapi-mcp

## Integrations

- USDC on Base for micropayments
- x402 payment enforcement
- MCP protocol
