## Overview

RobinX provides deployer-reputation and insider-flow intelligence for Robinhood Chain memecoins, computed from complete on-chain history since genesis.

## Features

- GET /verdict/{token} ($0.02) composite buy-risk verdict
- GET /deployer/{address} ($0.01) reputation rap sheet
- GET /feed/new ($0.01) pollable scored launch feed
- Public methodology and live out-of-sample calibration
- MCP server for agent integration
- Paid x402 endpoints on Base USDC
- No API key required

## Pricing

- $0.02 per composite buy-risk verdict
- $0.01 per deployer reputation check
