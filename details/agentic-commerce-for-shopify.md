## Overview

xpaysh reference Shopify App implementing ACP, UCP, and AP2 protocols. Composes with Shopify's native UCP path. Reference implementation, not production-hardened first-party path.

## Features

- Protocols: ACP, UCP, AP2
- Rails: x402, cards
- Type: Shopify App; composes with Shopify's native UCP path
- Maintainer: xpaysh (reference implementation)
