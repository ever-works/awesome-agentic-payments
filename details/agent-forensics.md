## Overview

Agent Forensics is an agent cost observability tool for Claude Code that analyzes JSONL session logs.

## Features

- Per-model cost breakdown
- Cache efficiency analysis
- Waste pattern detection (model misallocation, debug loops, sub-agent sprawl)
- Estimated savings calculations
- Free CLI: `npx agent-forensics analyze`
- x402 API: $5 basic / $15 full tier on Base

## Pricing

Free CLI; x402 API at $5 basic / $15 full tier on Base.
