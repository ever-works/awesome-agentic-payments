## Overview

Finance District Prism is a payment gateway for agentic commerce with x402 support, featuring SDKs for TypeScript, Python, and Java.

## Features

- Payment gateway for agentic commerce
- x402 support
- SDKs for TypeScript, Python, and Java
- Two-layer architecture:
  - Prism: orchestration — API, SDKs, middleware
  - Spectrum: on-chain stablecoin settlement across Base, Ethereum, Arbitrum, and BSC
