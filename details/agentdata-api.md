## Overview

AgentData API provides real-time crypto market data for AI agents with 16 pay-per-request endpoints on Base Mainnet.

## Endpoints

- Prices
- Funding rates
- Volatility
- Liquidation levels
- DeFi yields
- Cross-exchange arbitrage
- Technical indicators (RSI/MACD/BB/ATR)
- Support/resistance
- Sentiment
- Stablecoin health
- Historical OHLCV

## Deployment

Cloud-based on Base mainnet via x402 V2 with Bazaar discovery extension. Self-hosted facilitator, no accounts required.

## Pricing

Pay-per-request USDC micropayments on Base Mainnet. No accounts required.
