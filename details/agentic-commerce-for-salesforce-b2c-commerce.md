## Overview

xpaysh reference B2C Commerce cartridge implementing ACP, UCP, and AP2 protocols for Salesforce B2C Commerce. Includes PWA Kit extension. Reference implementation, not production-hardened first-party path.

## Features

- Protocols: ACP, UCP, AP2
- Rails: x402, cards
- Type: B2C Commerce cartridge + PWA Kit extension
- Maintainer: xpaysh (reference implementation)
