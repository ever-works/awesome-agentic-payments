## Overview

Romefeller.app is a document intelligence API for AI agents that processes invoices, NF-e, contracts, and receipts using a hybrid of regex pattern matching and Claude AI.

## Features

- PII scrubbing: email, CPF, CNPJ, phones, API keys
- Document completeness verification
- Risk assessment
- Structured field extraction from invoices, NF-e, contracts, and receipts
- 4 paid endpoints on Base mainnet
- Free regex preview at /preview (no payment required)
- No API keys, no signup
- x402 discovery via /.well-known/x402.json
- OpenAPI specification available
- llms.txt for agent discovery

## Pricing

- $0.005–$0.15 USDC per call on Base mainnet via Coinbase CDP facilitator
- Free regex preview at /preview

## Deployment

Cloud-hosted via Base mainnet x402 payment rail.
