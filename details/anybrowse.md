## Overview

AnyBrowse is an autonomous web browsing agent that converts URLs to LLM-ready Markdown using real Chrome browsers. It accepts x402 micropayments in USDC on Base.

## Features

- Autonomous web browsing agent
- Converts URLs to LLM-ready Markdown
- Real Chrome browsers
- x402 micropayments
- USDC on Base

## Pricing

- Pay-per-use via x402 USDC

## Deployment

Cloud-hosted at anybrowse.dev

## Integrations

- x402 payment protocol
- Base mainnet USDC
