## Overview

Pylon is an x402-payable utility API gateway designed for AI agents. It offers 20 capabilities spanning web extraction, search, translation, code execution, and image generation, all settled via USDC on Base mainnet.

## Features

- 20 capabilities: web extraction, search, translation, code execution, image generation, and more
- x402-payable utility API gateway
- Base mainnet USDC settlement
- MCP server: npx @pylonapi/mcp
- Agent reputation network
- Gateway orchestration
- Open source on GitHub

## Pricing

- Pay-per-call via x402 USDC on Base
