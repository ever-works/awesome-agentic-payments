## Overview

Royal Ruby x402 is a US consumer-rights law citation lookup API covering FCRA, FDCPA, TILA, state UDAP statutes, debt-collection rules, and credit-reporting timelines.

## Features

- FCRA citations
- FDCPA citations
- TILA citations
- State UDAP statutes
- Debt-collection rules
- Credit-reporting timelines
- Information-only, no legal advice

## Pricing

$0.05 USDC per call on Base mainnet.

## Deployment

Cloud-hosted API. Source: https://github.com/bshelby88/royal-ruby-x402
