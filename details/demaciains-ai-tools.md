## Overview

Demaciains AI Tools provides 19 pay-per-use API tools for AI agents, including content detection, email verification, SEO audit, and more. It uses manual x402 v2 protocol on Base and includes an MCP server.

## Features

- 19 pay-per-use API tools for AI agents
- AI content detection
- Email verification (DNS/MX)
- Company enrichment (web search)
- SEO audit
- Tech stack detection
- Plagiarism check
- Lead scoring
- Social audit
- Market analysis
- Prompt optimization
- Premium tools: $2.44, standard: $1.39
- Manual x402 v2 protocol on Base
- MCP server included
- Agent discovery via .well-known/agent.json
- Open source on GitHub

## Pricing

- Standard tools: $1.39 USDC
