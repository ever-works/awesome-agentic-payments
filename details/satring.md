## Overview

Satring is a curated API directory supporting both L402 (Lightning) and x402 (USDC on Base) protocols. It features human ratings, health monitoring, and an MCP server for AI agent discovery of paid APIs.

## Features

- Curated L402 + x402 API directory
- Human ratings and health monitoring
- MCP server for AI agent discovery
- Dual-protocol support: Lightning + USDC on Base
- Open source on GitHub
- MCP server available on PyPI (satring-mcp)

## Pricing

- Free browse and discovery
