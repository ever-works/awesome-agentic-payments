## Overview

Sentinel Payment Preflights is a free local MCP server that deterministically checks decoded x402 v2 PaymentRequired JSON against a scoped exact-EVM EIP-3009 safety profile.

## Features

- Deterministic x402 v2 PaymentRequired JSON validation
- Scoped exact-EVM EIP-3009 safety profile
- No network requests
- No wallet access, signing, or settlement
- Local MCP server

## Pricing

Free.

## Deployment

Local MCP server
