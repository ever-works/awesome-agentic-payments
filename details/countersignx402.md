# @countersign/x402

## Overview
Spend governance for agents that pay over x402.

## Features
- Parse the 402 challenge
- Check against spend policy pre-flight
- Per-tx/daily caps
- Allowlists
- Decoy-resistant asset pinning
- Pay only on allow
- Sub-second kill switch
- Signed hash-chained audit ledger
- MCP tool: `countersign_guard_x402`

## Pricing
Free and open source.

## Deployment
Client-side SDK, no server deployment required.
