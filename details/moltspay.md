# MoltsPay

## Overview
Payment infrastructure for AI agents with x402 support.

## Features
- CLI
- TypeScript SDK
- LangChain integrations
- CrewAI integrations
- Gasless payments
- Multi-chain: Base, Polygon, Solana, BNB, Tempo
- Spending limits

## Pricing
Free and open source.

## Deployment
Client-side SDK and CLI, no server deployment required.

## Integrations
- npm package: `moltspay`
- GitHub: https://github.com/Yaqing2023/moltspay
