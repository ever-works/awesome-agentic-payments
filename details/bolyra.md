## Overview

Bolyra is an agent identity verification and authorization layer for x402 endpoints, offering ZKP-backed credential proofs, scoped delegation with spending caps, and signed proof-envelope receipts.

## Features

- ZKP-backed credential proofs
- Scoped delegation with spending caps
- Signed proof-envelope receipts
- TypeScript SDK
- Python SDK
- CLI
- Gateway
- Circom circuits
- Demo playground
