# agent-payment-guard

## Overview
Pre-pay risk gate for autonomous payment agents.

## Features
- Claude Agent SDK `PreToolUse` hook
- Framework-agnostic `paymentGuard()`
- Blocks prompt-injected destinations
- Blocks intent mismatches
- Blocks overcharges before agent signs
- Fail-closed by default
- Zero-dep mock demo
- Optional live x402 firewall (402Sentinel)

## Pricing
Free and open source.

## Deployment
Client-side hook/library, no server deployment required.

## Integrations
- npm package: `@kaditang/agent-payment-guard`
- GitHub: https://github.com/kaditang/agent-payment-guard
