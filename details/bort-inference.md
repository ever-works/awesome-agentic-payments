## Overview

BORT Inference provides OpenAI-compatible LLM chat completions for AI agents on BNB Chain.

## Features

- OpenAI-compatible LLM chat completions
- deepseek-v4-flash model
- POST /v1/chat/completions
- Settled with EIP-3009 transferWithAuthorization
- x402 scheme exact/eip3009 on eip155:56
- Facilitator sponsors gas — buyer needs only $U
- No account, no API key
