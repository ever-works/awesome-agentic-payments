## Overview

x402station.io is an independent risk-signal layer for x402 agentic commerce.

## Features

- Probes x402 endpoints (decoy / zombie / price-trap / never-paid)
- Returns endpoint evidence before an agent authorizes payment
- MCP + REST interfaces
- Open x402-signals specification

- npm: https://www.npmjs.com/package/x402station-mcp
