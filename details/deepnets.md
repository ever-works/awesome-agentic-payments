## Overview

Deepnets provides Solana token intelligence via x402 USDC micropayments on Solana mainnet.

## Endpoints

- /api/token-safety/{mint}
- /api/token-details/{mint} (full holder + network breakdown)
- /api/holder-analysis/{mint}
- /api/social_research/{mint}
- /api/wallet-details/{address}
- /api/network-details/{networkAddress}
- /api/trending
- /api/watchlist
- /api/flagged-tokens

## Deployment

Cloud-based on Solana mainnet via x402.

## Pricing

$0.01 basic / $0.15 holder analysis USDC on Solana. Gas sponsored by the facilitator — no SOL needed.
