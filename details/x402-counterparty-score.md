## Overview

x402 Counterparty Score provides trust verdicts for x402 endpoints and pay-to addresses.

## Features

- Trust verdict (trusted/caution/avoid)
- Wash-trading ratio, real-buyer count, and repeat-buyer rate
- Deterministic economic-authenticity scoring computed from public on-chain settlement data
- Refreshed daily

- $0.02 USDC per call on Base via CDP facilitator
- Free sample tool for schema validation
- No API keys
