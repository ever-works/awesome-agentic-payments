## Overview

x402 Token Safety Scan provides live Base ERC-20 honeypot and safety scanning for AI trading agents, computing all verdicts from raw Base chain data.

## Features

- sellable/isHoneypot detection via live buy+sell eth_call simulation
- Buy/sell tax analysis in basis points (bps)
- Owner-renounced status check
- Uniswap v3 WETH pool liquidity analysis
- Overall safety verdict
- 100% computed from raw Base chain — no third-party data
- Auditable and reproducible results

## Pricing

$0.01 USDC per call on Base mainnet, no API key required.
