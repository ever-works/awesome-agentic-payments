## Overview

Crysha Price Oracle provides aggregated cryptocurrency prices from multiple sources, including BTC and other assets, priced at $0.001 per call on Base USDC.

## Features

- Aggregated crypto prices
- Multi-source BTC and other asset prices
- $0.001 per call on Base USDC
- Manifest at /.well-known/x402

## Pricing

- $0.001 per call on Base USDC

## Deployment

Cloud-hosted at api.crysha.com

## Integrations

- x402 payment protocol
- Base mainnet USDC
- .well-known/x402 discovery
