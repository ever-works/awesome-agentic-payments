## Overview

Seneschal provides Monero & Zcash payment watching for AI agents using read-only view keys and webhook notifications.

## Features

- Monero & Zcash payment watching via view key (read-only)
- HMAC-signed POST webhook for every inbound XMR/ZEC payment
- Watches run on operator's own full nodes
- Credit-metered: $0.02/day + $0.005/event
- Top up via x402 USDC or natively in XMR/ZEC
- Historical note scans
- Free Zcash UFVK derivation
- Live XMR/ZEC chain facts from $0.001
- DeFi liquidation telemetry (Aave, Morpho, Spark, Compound at-risk borrowers)
- Ethereum builder bid distributions
- Settles via Coinbase CDP with Bazaar discovery on every route
- REST + MCP, no API keys

## Pricing

## Deployment

Cloud-hosted with full nodes, settlement via Coinbase CDP x402 payment rail.
