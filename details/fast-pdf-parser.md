## Overview

Fast PDF Parser is a pay-per-parse PDF text extraction API for AI agents, served from Cloudflare Workers edge using LiteParse WASM.

## Features

- POST raw PDF bytes
- Structured JSON text output
- Born-digital PDFs (no OCR)
- 10MB file cap
- Sub-100ms parse time
- SHA-256-bound payment proofs with replay protection
- x402 Bazaar discovery metadata
- Settlement via Coinbase CDP facilitator
- No API keys, no signup

## Pricing

$0.002 USDC per document on Base.
