# AlgoVoi

## Overview
Multi-chain x402 facilitator.

## Features
- EVM: Base, Tempo
- SVM: Solana
- AVM: Algorand, VOI
- Stellar support
- Hedera support
- Single endpoint
- Native Solana Pay `reference` pubkey binding (cryptographic tx↔order correlation without memos)
- Implements MPP and AP2 at the same URL
