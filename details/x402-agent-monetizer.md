# x402-agent-monetizer

## Overview
Drop-in `@paywall` decorator for FastAPI.

## Features
- `@paywall` decorator gates any endpoint behind USDC on Base
- Companion `Client` class (auto-pay + retry)
- Sync/async support
- Preserves FastAPI dependency injection via `inspect.signature.replace()`
- MIT license
- Python 3.10+
- 3 passing tests

## Pricing
Free and open source (MIT).

## Deployment
Server-side Python library.
