## Overview

Apollo Intelligence Network provides 27 x402 endpoints for AI agents covering intelligence feeds, crypto prices, OSINT, DeFi yields, real-time social search, and proxy infrastructure. It includes an MCP server with 26 tools.

## Features

- 27 x402 endpoints for AI agents
- Intelligence feeds: pain points, agentic trends, sentiment
- Crypto prices
- OSINT: IP/domain intelligence
- DeFi yields
- Real-time X/Twitter search
- Proxy infrastructure
- Bundles
- MCP server with 26 tools
- USDC on Base
- Open source on GitHub
- npm package: @apollo_ai/mcp-proxy

## Pricing

- Pay-per-call via x402 USDC on Base
