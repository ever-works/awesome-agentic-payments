## Overview

SIBYL is an autonomous crypto intelligence agent on Base that provides three x402 endpoints for token scoring, rug/honeypot detection, and builder shipping velocity analysis. It is ERC-8004 registered.

## Features

- Autonomous crypto intelligence agent on Base
- Three x402 endpoints:
  - Token scoring ($0.05)
  - Rug/honeypot detection ($0.02)
  - Builder shipping velocity vs. market cap analysis ($0.10)
- ERC-8004 registered (Agent #20880)
- USDC on Base
- Discovery via Agent Card
- Domain Verification

## Pricing

- Token scoring: $0.05 USDC
- Rug/honeypot detection: $0.02 USDC
- Builder shipping velocity analysis: $0.10 USDC
