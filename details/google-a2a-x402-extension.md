## Overview

Google A2A x402 Extension is an agent commerce protocol that extends Google's Agent-to-Agent (A2A) protocol with x402 payment integration. It enables multi-agent payment orchestration with a payment-required, payment-submitted, payment-completed flow.

## Features

- Python and TypeScript implementations
- Payment-required, payment-submitted, payment-completed flow
- Multi-agent payment orchestration
- x402 payment integration
- Google A2A protocol compatible

## Pricing

Free and open source.

## Deployment

Self-hosted.
