# cipher-x402-client

## Overview
Lightweight TypeScript/JavaScript x402 v2 client library.

## Features
- Zero runtime dependencies
- Native fetch
- ESM + CJS dual build
- 34 tests, 89% coverage
- Node 18+ / browsers support
- Optional `ethers` peer dep for signing

## Pricing
Free and open source.
