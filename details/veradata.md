## Overview

VeraData provides verified Latin American data for autonomous AI agents through 5 x402 endpoints. It covers sanctions screening, entity enrichment, central bank rates, business registry lookup, and LATAM market context, with no API key required.

## Features

- Verified Latin American data for autonomous AI agents
- 5 x402 endpoints
- Sanctions screening: OFAC SDN + SARLAFT Colombia + CNBV Mexico + COAF Brazil + UAF Chile (20K+ entries, EU AI Act Art.13 audit hash)
- Entity enrichment: RUES/CNPJ/RFC registries
- Real-time central bank rates: DTF/TIIE/Selic/TRM/UF for CO/MX/BR/CL/PE
- Business registry lookup
- AI-powered LATAM market context
- $0.02–$0.10 USDC on Base and Solana
- MCP server at /mcp
- No API key — any agent with a wallet can call it
- Open source on GitHub
