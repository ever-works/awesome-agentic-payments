## Overview

x402 Surface Check is a no-payment CLI and GitHub Action for reviewing x402 implementation before launch.

## Features

- Reviews x402 manifests
- Reviews OpenAPI specs
- Reviews HTTP 402 challenges
- Browser CORS/payment-header behavior review
- Cache policy review
- Resource binding review
- Price/rail drift review

## Pricing

No payment required.
