## Overview

agentdata-nl provides European company screening for AI agents from official public registers via x402 v2 with Bazaar discovery extension.

## Features

- Company registers: UK, FR, NO, CH, CZ, FI, PL
- Insolvency checks: NL, FR
- EU + UN sanctions screening
- EU VAT (VIES)
- LEI
- MiCA crypto-firm and token-registry checks
- EURC peg monitoring
- x402 counterparty pre-payment trust check

## Deployment

Cloud-based on Base mainnet via CDP facilitator.

## Pricing

18 endpoints, $0.002–$0.18 per call, all-or-nothing billing (only charged when the task fully completed). No API keys, no signup required.
