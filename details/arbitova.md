## Overview

Arbitova is an escrow and AI arbitration platform for agent-to-agent payments.

## Features

- Escrow for agent-to-agent payments
- Transparent AI arbitration (N=3 LLM majority vote with tiebreaker)
- Sub-task chained escrow for agent swarms
- External arbitration API
- 0.5% success fee, 2% dispute only
- 8 MCP tools
- npm SDK: @arbitova/sdk
- MCP: @arbitova/mcp-server

## Pricing

0.5% success fee, 2% dispute fee.

## Deployment

MCP server and SDK (npm); docs at arbitova.com/docs.
