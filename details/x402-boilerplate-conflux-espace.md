## Overview

x402 Boilerplate for Conflux eSpace is a production-ready paid AI API template. It provides a complete stack for building x402-powered APIs with PHP backend, Node.js facilitator, and CLI agent.

## Features

- PHP backend
- Node.js facilitator
- CLI agent
- Docker support
- 87 tests
- Multi-wallet demo
- EIP-3009 USDT0 settlement
- Live demo available

## Pricing

Open source (repository available)

## Deployment

Self-hosted via Docker
