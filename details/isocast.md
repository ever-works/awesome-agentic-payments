## Overview

Isocast provides per-signal Polymarket weather-market data, emitting signals when city temperatures cross into new Polymarket temperature buckets. It covers 37 cities and provides market URLs, readings, and live odds.

## Features

- Per-signal Polymarket weather-market data
- Signal on temperature bucket crossing
- Market URL, old/new reading, live odds for every bucket
- 37 cities covered
- From $0.01 USDC on Base
- MCP server on npm (isocast-mcp)

## Pricing

- From $0.01 USDC per signal on Base

## Deployment

Cloud-hosted at api.isocast.dev

## Integrations

- x402 payment protocol
- Base mainnet USDC
- MCP server via isocast-mcp npm package
