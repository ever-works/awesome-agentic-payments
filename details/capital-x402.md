## Overview

Capital x402 is an agent micro-utility service that enables AI agents to pay for utility API calls via x402 USDC micropayments on Base mainnet.

## Features

- Agent micro-utilities paid via x402 USDC on Base mainnet
- Pricing from $0.001 USDC per call (value-tiered)
- Stable discovery on voidd.live
- Live paid host listed in paid-url.json when rail is public
- agent.json discovery endpoint
- x402 Bazaar manifest support
- paid-url.json for live host discovery

## Pricing

- From $0.001 USDC per call on Base mainnet
- Value-tiered pricing model

## Deployment

Cloud-hosted on voidd.live

## Integrations

- x402 payment protocol
- Base mainnet USDC
- agent.json discovery
- x402 Bazaar manifest
