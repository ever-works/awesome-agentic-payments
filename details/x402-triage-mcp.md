## Overview

x402 Triage MCP is an MCP server for no-payment x402 launch-surface triage, 402 Index health checks, and paid-review handoff.

## Features

- x402 launch-surface triage
- 402 Index health checks
- Paid-review handoff
- Tools: triage_x402_surface, watch_402_index, x402_paid_paths

## Pricing

No payment required.
