## Overview

HSH Data-on-Demand provides made-to-order B2B data for AI agents on Base mainnet, with custom quotes and per-call USDC payments via x402.

## Features

- Describe any data need in plain language
- Receive a custom quote
- Pay per call in USDC via x402
- Live company intelligence (hsh_company_intelligence at $0.02/call)
- Free /v1/quote-smart discovery
- Arbitrary data fulfillment: lead lists, contact enrichment, custom pulls
- Quoted by scope ($1–$50)
- No signup, no API keys
- HTTP API and MCP Streamable HTTP transports
- Agent manifest at /.well-known/agent-manifest.json
- x402 catalog

## Pricing

- $0.02/call for company intelligence
- Custom quotes: $1–$50 by scope

## Deployment

Cloud-hosted on Base mainnet via x402 payment rail.
