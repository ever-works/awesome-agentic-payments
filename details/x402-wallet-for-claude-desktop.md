## Overview

x402 Wallet for Claude Desktop is a native Claude Desktop extension that provides USDC wallet capabilities for AI agents.

## Features

- Native Claude Desktop extension (.mcpb one-click install)
- USDC wallet on Stellar and Base
- Three tools: check_balance, pay, x402_fetch
- Automatic 402 payment handling
- Configurable budget limits per call and per day
