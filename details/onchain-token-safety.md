## Overview

OnChain Token Safety provides multi-chain token-safety verdicts for AI agents via x402 USDC micropayments.

## Features

- Rug/honeypot verdict (0–100 + evidence)
- Live sell-simulation
- Ownership/privilege checks
- Size-aware exit-safety
- Wallet drainer-approval + address-poisoning scans

## Chains Covered

PulseChain, Monad, Base & BSC

## Deployment

Cloud-based on Base mainnet via self-hosted settlement.

## Pricing

$0.01–$0.05 USDC per call.
