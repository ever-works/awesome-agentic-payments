## Overview

EP AgentIAM is an agent identity and access management layer built on x402 payment rails. It provides 9 verification endpoints across 5 pillars for securing AI agent operations, with on-chain settlement on Base.

## Features

- 5-pillar agent identity and access layer
- 9 x402-payable verification endpoints
- NoLeak: execution integrity verification
- MemGuard: memory state verification
- RiskOracle: pre-action risk scoring
- SecureExec: tool execution security
- FlowCore: full orchestration pipeline
- All 9 endpoints verified healthy on 402index.io
- Agent discovery via /.well-known/agent.json and /.well-known/mcp.json
- Documentation and quickstart available

## Pricing

- $0.01-$0.02 USDC per call on Base

## Deployment

Cloud-hosted on Render
