## Overview

SYNTHORA md-extract converts Western EN/EU web content to clean markdown with token budget for AI agents.

## Features

- Western EN/EU web → clean markdown
- Token budget for AI agents
- Ed25519 attestation receipt with every response for offline cryptographic verification
- Cryptographic chain-of-custody
