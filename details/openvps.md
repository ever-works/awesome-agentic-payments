## Overview

OpenVPS is AI-agent VPS hosting that accepts USDC payments on Base, Celo, or Tempo. It provides root SSH access to Ubuntu 24.04 Firecracker microVMs, with support for both x402 and MPP payment protocols.

## Features

- AI-agent VPS hosting
- Pay USDC on Base, Celo, or Tempo
- Root SSH to Ubuntu 24.04 Firecracker microVMs
- Provision in seconds
- Supports x402 + MPP dual-protocol
- From $0.005/hr
- Skill.md available
- OpenAPI specification
- Open source on GitHub
