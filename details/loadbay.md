## Overview

Loadbay is a catalog of open-source AI-agent harnesses with x402 tipping support.

## Features

- 370+ open-source AI-agent harnesses
- MCP servers, SDKs, adapters
- 11 domains
- Agent-native: connect over MCP to search and list harnesses
- Authors earn USDC tips via x402 on Base and Solana
