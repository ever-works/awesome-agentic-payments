## Overview

Sentry Forge x402 generates consumer-debt dispute packs via a single x402-paid call on Base mainnet.

## Features

- 8-file dispute pack per call
- Collector dispute letter
- Original-creditor dispute letter
- CFPB complaints (collector + creditor)
- Credit-bureau disputes
- Court-records search guide
- Action checklist
- Evidence inventory
- Validated against real FDCPA/FCRA cases

## Pricing

$0.50 USDC per call on Base mainnet.

## Deployment

Cloud-hosted API. Source: https://github.com/bshelby88/sentry-forge-x402
