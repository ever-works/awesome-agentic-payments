## Overview

AEO Scanner (Convrgent) is an AI search visibility audit API for any website. It provides triple scoring: AEO (search findability), GEO (citation readiness), and Agent Readiness (agent interaction) with 55+ checks across 12 categories.

## Features

- AI search visibility audit
- Triple scoring: AEO, GEO, Agent Readiness
- 55+ checks across 12 categories
- Free scan via SIWX
- Full audit: $1 USDC
- Fix code: $5 USDC
- x402 payment integration on Base & Solana
- MCP server available
- Cursor Directory integration
