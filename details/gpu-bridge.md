## Overview

GPU-Bridge is a 30-service GPU inference API with native x402 payments on Base L2.

## Features

- 30 GPU inference services
- Native x402 payments (USDC on Base L2)
- LLM inference
- Image generation
- Embeddings
- STT (speech-to-text)
- TTS (text-to-speech)
- PDF processing
- All in one API
- Agents pay per call with no human intervention

## Pricing

Per-call via x402 on Base L2.

## Deployment

API hosted at gpubridge.xyz
