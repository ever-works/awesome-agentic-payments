## Overview

ProxyLLM LLM Cost Scout helps AI agents optimize LLM costs by finding the right ChatGPT/Codex subscription tier.

## Features

- Send a monthly OpenAI API bill
- Get back the flat ChatGPT/Codex subscription tier that absorbs it through the ProxyLLM gateway
- Exact new total, savings, live model catalog
- Machine-readable agent signup steps (email OTP, no browser)
