## Overview

KR Crypto Intelligence is a Korean crypto market data API providing Kimchi Premium data, exchange prices, and AI-powered sentiment analysis for the Korean market. It supports multiple chains and is open source.

## Features

- 11 paid endpoints
- Real-time Kimchi Premium across 180+ tokens
- Upbit/Bithumb prices
- AI-powered Korean sentiment analysis (world's first)
- Global vs Korea divergence with structured AI breakdown
- Market alerts
- $0.001-$0.10 USDC per call on Base, Polygon, and Solana
- Open source on GitHub

## Pricing

- $0.001-$0.10 USDC per call depending on endpoint and chain
