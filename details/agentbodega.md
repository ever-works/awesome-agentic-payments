## Overview

AgentBodega is an agent-ready paid API shelf with 51 x402-payable endpoints covering public-data, social-media, cloud/status, domain, artifact, launch-readiness, and x402-inspection.

## Deployment

Cloud-based on Base mainnet via x402 USDC micropayments.

## Pricing

USDC on Base. No API keys or signup required.
