## Overview

hundun.app is a pay-per-call AI document summarization API for AI agents, supporting long-context input up to 200K characters.

## Pricing

- $0.05 USDC per call on Base

## Features

- Long-context (up to 200K chars)
- Auto-language detection (Chinese/English tested)
- No API keys, no signups

## Integrations

- USDC on Base for micropayments
- x402 payment enforcement
