## Overview

Crypto Data Agent provides live crypto prices and DeFi yield pools for AI agents via x402 payments.

## Features

- Live crypto prices (up to 25 coins per call)
- DeFi yield pools (APY/TVL with chain/stablecoin filters)
- Dual-rail payments on Base and Solana mainnet
- Gas sponsored by the facilitator — no ETH/SOL needed
- Bazaar-listed
- Free live sample at /api/sample

## Pricing

- ~$0.002 USDC per call

## Deployment

Cloud API
