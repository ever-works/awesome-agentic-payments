## Overview

agentsvc.io provides 20 utility tools for AI agents via x402 USDC micropayments on Base.

## Tools

ip-lookup, dns-lookup, qr-code, exchange-rates, email-validate, ssl-check, phone-validate, weather, translate, whois, crypto-prices, stock-prices, geocode, web-search, news-search, pdf-extract, screenshot, webpage-reader, html-to-pdf, ocr

## Deployment

Cloud-based on Base mainnet via x402 USDC micropayments.

## Pricing

$0.001–$0.008 USDC per call. No API keys, no signup required.
