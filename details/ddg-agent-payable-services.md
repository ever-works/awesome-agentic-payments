## Overview

DDG Agent-Payable Services offers 83 AI-agent-native services spanning checkout/payment conformance, security scanning, lookups, media generation, code execution, and multi-model agent runs.

## Features

- 83 AI-agent-native services
- Checkout/payment conformance
- MCP/tool security
- Prompt injection scans
- DNS/WHOIS lookups
- Screenshots
- QR codes
- PDF/OCR extraction
- Price feeds
- Code execution (Docker sandbox)
- GPU embeddings (Ollama nomic-embed-text)
- Image generation (Stable Diffusion on GTX 1080)
- Multi-model agent-run (GLM/Claude/Codex)
- 82/83 fully automated (zero human in loop)
- Identity-first flow: 403→402→receipt
- 5 settlement networks: Base, Polygon, Arbitrum, World Chain, Solana USDC
- 13 direct-crypto asset families
