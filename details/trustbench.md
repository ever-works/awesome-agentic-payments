## Overview

TrustBench is a non-custodial routing and audit layer on top of x402. It provides Ed25519-signed receipts with on-chain settlement evidence that can be verified offline.

## Key Features

- Non-custodial routing and audit layer for x402
- Ed25519-signed receipts
- On-chain settlement evidence, verifiable offline
- Fail-safe paywall on Base via Coinbase CDP facilitator
- Verifier available as npm package: @trustbench/verify-receipt

## Deployment

Web service at trustbench.io, npm package for verification.
