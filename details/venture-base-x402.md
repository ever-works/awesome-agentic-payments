## Overview

venture-base-x402 is an x402 v2 paid download service on Base mainnet that provides a deploy-ready HTTP-402 boilerplate starter kit. It uses the permissionless xpay facilitator for machine-to-machine settlement.

## Features

- x402 v2 paid download on Base mainnet (eip155:8453)
- GET /starter-kit ($0.10 USDC) returns agent-payments-starter kit .zip
- Deploy-ready HTTP-402 boilerplate
- Settled via permissionless xpay facilitator
- No API key, no signup
- Free /health endpoint
- x402 Bazaar discovery in 402 challenge and /openapi.json
- /.well-known/x402 and agent-card discovery

## Pricing

- /starter-kit: $0.10 USDC
- /health: free

## Deployment

Cloud-hosted on Vercel
