## Overview

Vault Pro x402 is an Obsidian project and agent scaffolder that returns a complete markdown document fitted to the Vault Pro template structure.

## Features

- Complete markdown document output
- Frontmatter
- Goal definition
- Success criteria
- Decomposition table
- Hermes coordination notes
- Two routes: scaffold-project and scaffold-agent
- Useful for AI orchestrators registering new specialized agents

## Pricing

$0.05 USDC per call on Base mainnet.

Cloud-hosted API. Source: https://github.com/bshelby88/vault-pro-x402
