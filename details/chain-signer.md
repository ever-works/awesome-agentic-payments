## Overview

chain-signer is a non-custodial wallet for AI agents that enables burner wallet creation and local signing, including EIP-712 typed data for x402 payment authorizations.

## Features

- Create burner wallet in one call
- Local signing including EIP-712 typed data for x402 payment authorizations
- No password prompt, no signup, no custody
- Pure Python
- MCP server with 6 tools: create_wallet, balance, send, swap, etc.

## Pricing

Open source, free to use.
