## Overview

nohumans.directory is a discovery and trust layer for paid x402 services. Unlike static catalogs, every listing is continuously re-probed and scored based on real uptime data, providing dynamic reputation scores for AI agent service discovery.

## Features

- Discovery and trust layer for paid x402 services
- Every listing re-probed every 15 minutes
- Recency-weighted longitudinal reputation scoring
- Lifecycle: unverified → verified → failing based on real uptime data
- Free /v1/discover REST API
- MCP server at /mcp
- Free demand-intelligence feed at /v1/demand
- No dashboard required, all over HTTP
- USDC on Base
