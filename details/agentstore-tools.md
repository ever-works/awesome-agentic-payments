## Overview

AgentStore is an open-source marketplace for Claude Code plugins that uses x402 USDC payments. It features an 80/20 publisher revenue split and permissionless publishing via CLI.

## Features

- Open-source marketplace for Claude Code plugins
- x402 USDC payments
- 80/20 publisher revenue split
- Permissionless publishing via CLI

## Pricing

- Pay-per-use via x402 USDC
- 80/20 publisher revenue split

## License

Open source

## Deployment

Cloud-hosted at agentstore.tools

## Integrations

- x402 payment protocol
- Base mainnet USDC
- Claude Code
