## Overview

ScoutScore is trust scoring infrastructure for x402 services, monitoring over 1,700 services with continuous health checks and fidelity probes.

## Features

- Monitors 1,700+ x402 services
- Continuous health checks
- Fidelity probes
- 4-pillar scoring model: Contract Clarity, Availability, Response Fidelity, Identity & Safety
- API documentation
- npm SDK (@scoutscore/sdk)
- MCP server (@scoutscore/mcp-server)

## Pricing

Freemium model.

## Deployment

Cloud-hosted at scoutscore.ai
