## Overview

x402 Dynamic Pricing is a surge pricing engine that leverages x402 V2's dynamic getAmount callback to adjust prices based on demand. Includes an interactive simulator for testing.

## Features

- Demand-based surge pricing engine
- Uses x402 V2's dynamic getAmount callback
- Sliding window pricing algorithm
- 5-tier interpolation
- EMA smoothing
- Interactive Svelte 5 simulator
