## Overview

ALFRED is a self-hosted personal-assistant paid tools platform with 21 endpoints spanning vision, long-context reasoning, image generation, transcription, and more.

## Features

- 21 endpoints across vision and long-context reasoning
- RTX 5090 with 256k context
- FLUX image generation
- Custom SDXL/FLUX character LoRA training
- Whisper transcription
- Article, PDF, YouTube extraction
- Wikipedia + Hacker News access
- Physical WeatherFlow Tempest sensor readings
- Dual rail: Lightning and USDC on Base
- Coinbase CDP Facilitator integration

## Pricing

- Lightning: $0.02–$100
- USDC on Base: $0.02–$100

## Deployment

Self-hosted.

- Lightning Network

- USDC
