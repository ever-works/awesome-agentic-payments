## Overview

YieldSignal provides real-time risk-weighted USDC lending APY across multiple protocols on Base.

## Features

- Real-time risk-weighted USDC lending APY
- Aave, Compound, Morpho, Moonwell, Euler and Fluid on Base
- Every reading tagged with its data source (onchain/api/defillama)
- Sources that fail are omitted, never estimated
- Bazaar discoverable

## Pricing

$0.01 USDC per call via CDP Facilitator.

## Integrations

- x402 payment protocol on Base (eip155:8453)
