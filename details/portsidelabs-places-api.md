## Overview

PortsideLabs Places API is a Google Places API v1 proxy that provides place detail lookup and full-text search via x402 pay-per-request access.

## Pricing

- $0.001 USDC per call

## Features

- Place detail lookup
- Full-text search
- Google Places API v1 proxy

## Integrations

- USDC on Base mainnet and Solana mainnet for micropayments
- x402 payment enforcement
