## Overview

Azeth MCP Server provides x402 payment capabilities and on-chain reputation scoring for AI agents.

## Features

- x402 payment tool (azeth_pay)
- ERC-8004 trust registry discovery
- On-chain reputation scoring
- Payment agreements for recurring x402 billing
- USDC on Base
- Available on npm as @azeth/mcp-server
