## Overview

PROWL provides 47 real-world data feeds for AI agents covering prediction markets, economics, weather, geopolitics, narrative, and crypto. Data is paid per-call via x402 micropayments.

## Features

- 47 real-world data feeds
- Prediction markets, economics, weather, geopolitics, narrative, crypto
- Paid per-call via x402
- MCP server for Claude and compatible agents

## Pricing

Pay-per-call via x402 micropayments.

## Integrations

- x402 payment protocol
- MCP server
