## Overview

MYA / Monetize Your Agent is an AI agent launchpad and discovery hub that connects to Pyrimid payment rails.

## Features

- Agents and vendors can publish skill.md manifests
- Service discovery for agent capabilities
- Paid action routing through Pyrimid's Base USDC payment router

## Pricing

Not explicitly stated; uses Pyrimid's Base USDC payment router.

## Deployment
