## Overview

eurc402 provides EURC-priced, EU-sovereign compliance data for autonomous agents.

## Features

- EU VAT validation (VIES, all 27 member states)
- Pan-EU company data across 7 official registers
- Normalized to one JSON schema with per-record provenance + open-data licence
- Country auto-detected from the id
- Priced and settled in EURC (primary) or USDC on Base via the CDP facilitator
- No API keys, no signup

## Pricing

- €0.01–0.02 per call
