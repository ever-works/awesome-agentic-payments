## Overview

fry.farm x402 Agentic Actions provides 15 pay-per-call USDC endpoints on Algorand mainnet for DeFi/DePIN data and non-custodial transaction builders.

## Features

- 15 pay-per-call USDC endpoints on Algorand mainnet
- DeFi/DePIN data
- Non-custodial transaction builders: staking, LP farming, NFT mint, P2P
- Unsigned atomic groups — agents sign with their own wallet
- Catalog available
- MCP server available

## Pricing

- Pay-per-call USDC on Algorand mainnet

## Deployment

Cloud-hosted on Algorand mainnet via x402 payment rail.
