## Overview

Pinata 402-server is a code repository for Pinata's x402 payment integration on IPFS. It enables pay-to-pin functionality on IPFS with x402 payments.

## Key Features

- x402 payment integration for IPFS
- Pay-to-pin functionality
- Code repository for developers
- Pinata cloud storage integration

## Deployment

Self-hostable from GitHub repository.
