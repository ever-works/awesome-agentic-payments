## Overview

JubJub MCP is an MCP server for media publishing and on-chain royalty management.

## Features

- 65 MCP tools
- Media publishing
- Cross-platform analytics
- Automated on-chain royalty splits
- Agents publish content
- Track performance
- Surface claimable USDC balances autonomously
- Endpoint: api.jubjubapp.com/v2/mcp
