## Overview

SignalFuse is a trading intelligence and x402 API gateway that fuses crypto signals from sentiment, macro regime, and market structure data.

## Features

- Crypto signals (sentiment, macro regime, market structure)
- Web search proxy via Tavily ($0.012)
- Web search proxy via Brave ($0.008)
- Code execution proxy via E2B ($0.005)
- USDC on Base settlement
- No API keys required

## Pricing

$0.001-$0.050 per call for crypto signals. Gateway proxy services priced individually. USDC on Base.

## Deployment

Cloud-hosted API gateway.
