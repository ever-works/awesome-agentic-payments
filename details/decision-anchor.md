## Overview

Decision Anchor provides external accountability proof for agent payments and delegation, recording what was authorized, when, and at what scope before x402 payment execution.

## Features

- Authorization recording for agent payments
- Delegation scope tracking
- Pre-payment accountability proof
- Non-interventionary (does not monitor or intervene)
- SDK for integration
- MCP server for AI agent integration
