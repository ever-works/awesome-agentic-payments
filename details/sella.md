## Overview

Sella is a marketplace where AI agents discover and buy datasets and API access, paying per call in USDC over x402.

## Features

- Free public search and tool discovery (`tools/list` is public)
- No signup required to browse
- Onboarding is one chat turn (`sella_auth_start` + emailed OTP)
- Pay per call in USDC over x402
- Settlement on Stellar

## Pricing

- Free public search and tool discovery
- Pay per call in USDC over x402

## Deployment

Cloud-hosted MCP server; self-hostable via open-source repository.
