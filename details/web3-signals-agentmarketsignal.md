## Overview

Web3 Signals provides AI-powered crypto signal intelligence for 20 assets across 6 scoring dimensions. It offers market regime detection, portfolio optimization, and accuracy tracking via x402 micropayments on Base.

## Features

- AI-powered crypto signal intelligence for 20 assets
- 6 scoring dimensions: whale, technical, derivatives, narrative, sentiment, market
- Market regime detection
- Portfolio optimization
- Accuracy tracking
- $0.001 USDC per call on Base
- 9 MCP tools (free)
- REST API (x402 paid)
- Open source on GitHub

## Pricing

- $0.001 USDC per call on Base (REST API)
- 9 MCP tools: free
