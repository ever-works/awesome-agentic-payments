## Overview

agentfeeds.jp provides Japan-focused regulatory, sanctions, and DEX market data for AI agents. It offers 27 paid endpoints covering Japanese regulatory events, sanctions screening, and Base DEX market statistics.

## Features

- 27 paid endpoints
- FSA/e-Gov regulatory events (Japan)
- MOF/OFAC sanctions screening
- Base DEX spread/peg statistics
- REST API
- MCP interface
- Pay-per-endpoint pricing

## Pricing

- $0.001–0.05 USDC per endpoint

## Deployment

Cloud-hosted; accessible at api.agentfeeds.jp
