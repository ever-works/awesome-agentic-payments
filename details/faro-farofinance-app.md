## Overview

Faro is a verify-before-pay trust API for AI agents. It provides red/yellow/green verdicts for URLs, payees, and payment counterparties before settlement, with Ed25519 trust receipts anchored on Base.

## Features

- Verify-before-pay trust API for AI agents
- Red/yellow/green verdicts for URLs, payees, and counterparties
- Supports x402, AP2, and ACP payment counterparties
- Advisory service (pre-settlement)
- Keyed REST API
- Hosted MCP server
- Ed25519 trust receipts
- Base-anchored transparency log

## Pricing

- Pay-per-use via x402

## Deployment

API at api.farofinance.app
