## Overview

img402 is image hosting for AI agents, where users upload an image, pay via x402, and receive a public CDN-backed URL.

## Features

- Image upload with x402 payment
- Public CDN-backed URL
- Three tiers:
  - Free: 1MB, 7-day retention
  - $0.01 USDC: 5MB, 1-year retention
  - $1: 5MB, permanent retention
- USDC on Base and Solana via Coinbase CDP facilitator
- Indexed in CDP Bazaar
- No API keys, no signup
- Claude/agent skills available
- OpenAPI specification
- llms.txt

## Pricing

- Free tier: 1MB, 7-day retention
- $0.01 USDC: 5MB, 1-year retention
- $1: 5MB, permanent retention

## Deployment

Cloud-hosted on Base and Solana via x402 payment rail.
