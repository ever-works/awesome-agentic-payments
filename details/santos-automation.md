## Overview

Santos Automation is a website intelligence MCP server for AI agents.

## Features

- SSRF-guarded safe fetch
- RSS/Atom/JSON feed parsing
- Page link maps
- Screenshots/PDF
- Page-to-markdown
- Schema-validated structured extraction
- Page summaries
- Quick and browser-rendered website audits
- Agent-readiness scoring
- Pay-per-call via x402 (USDC on Base mainnet)
- No accounts or API keys
- Free daily preview endpoints
- Streamable HTTP

## Pricing

- Free daily preview endpoints
- Pay-per-call via x402 (USDC on Base mainnet)

## Deployment

Cloud-hosted MCP server (Streamable HTTP); self-hostable via GitHub.
