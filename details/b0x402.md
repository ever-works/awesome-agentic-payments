## Overview

b0x402 is an AI-powered crypto intelligence API that provides meme coin signals, DeFi sentiment analysis, market equilibrium analysis, and wallet profiling on the Base network.

## Features

- Meme coin signals
- DeFi sentiment analysis
- Market equilibrium analysis
- Wallet profiling
- x402 USDC payment on Base
- Pay-per-call pricing model

## Pricing

- $0.01–0.10 USDC per call
