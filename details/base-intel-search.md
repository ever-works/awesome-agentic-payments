## Overview

Base Intel Search is a web search MCP tool for AI agents that provides ranked, de-duplicated results plus top news.

## Features

- Ranked, de-duplicated search results
- Top news results
- Filters: recency, site, count
- Auto-pays the upstream /search API per query
- ~$0.015 USDC on Base via x402
- Payment from the agent's own wallet
- No API key required
- npx -y base-intel-search-mcp

## Pricing

- ~$0.015 USDC per query on Base via x402

## Deployment

Cloud-hosted MCP server; npx package available.
