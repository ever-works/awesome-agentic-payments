## Overview

x402node is a comprehensive API marketplace with 528 pay-per-call endpoints for AI agents. It covers financial data, on-chain analytics, web extraction, and developer tools, all settled via USDC on Base through Coinbase CDP facilitator.

## Features

- 528 pay-per-call APIs for AI agents
- Real-time crypto/forex/stock/commodity prices
- On-chain data: gas, DeFi TVL, wallet analytics, whale tracking, token risk/honeypot
- Residential-IP web extraction
- Aviation and dev tools
- USDC on Base via Coinbase CDP facilitator
- No API keys required
- OpenAPI specification available
- .well-known/x402 manifest

## Pricing

- Pay-per-call via x402 USDC on Base

## Deployment

Cloud-hosted at api.x402node.dev
