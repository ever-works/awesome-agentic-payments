## Overview

SqueezeOS is an institutional market-intelligence MCP server from Script Master Labs focused on squeeze detection, options flow, and IWM 0DTE signals.

## Features

- Squeeze detection
- Options flow
- IWM 0DTE signals
- x402/HTTP-402 micropayment-gated premium endpoints
- Settles on Base and XRPL
- Free-tier tools with no auth

## Pricing

- Free-tier tools available
- Premium endpoints paid via x402/HTTP-402 micropayments
- Settles on Base and XRPL

## Deployment

Cloud-hosted MCP server; self-hostable via GitHub repository.
