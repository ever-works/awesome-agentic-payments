# monapi

## Overview
One-line API monetization SDK wrapping x402 setup.

## Features
- One-line x402 setup
- Express support
- Next.js support
- MCP support
- Per-route pricing
- Base/Arbitrum/Polygon
- Gas-free agent payments via EIP-3009
