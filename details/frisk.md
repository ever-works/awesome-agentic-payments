## Overview

Frisk is a pre-transaction screening SDK for agent payments that returns allow/review/block verdicts before an agent pays an x402 seller.

## Features

- allow/review/block verdict before agent pays x402 seller
- Checks V2 payTo swap
- Spending-policy violation detection
- Plaintext-HTTP quote detection
- Malformed or blocklisted counterparty detection
- TypeScript + Python SDK
- MIT license
- No runtime dependencies
- Lite mode runs offline with no API key
- Hosted reputation tier in early access
