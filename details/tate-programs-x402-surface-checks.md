## Overview

Tate Programs x402 Surface Checks provides paid public-surface readiness checks for x402, MPP, Pay.sh, A2A, and agent-skill launches.

## Features

- Four Base mainnet USDC endpoints for x402 launch triage
- 402 Index watch
- Agent-skill trust checks
- A2A payment-surface triage
- Supports x402, MPP, Pay.sh, A2A, and agent-skill launches

## Pricing

Paid service via USDC on Base mainnet.

## Deployment

Cloud-hosted at the402.tateprograms.com
