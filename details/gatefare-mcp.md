## Overview

Gatefare MCP is a marketplace MCP for paid HTTP APIs, enabling discovery, purchasing, and publishing of API services.

## Features

- 13 MCP tools
- Discovery: search, get, list, suggest
- Buyer: call_api (auto-handles 402 → sign → retry)
- Publisher: register, distribute
- Non-custodial USDC on Base
- Automatic x402 payment handling
- Usage: `npx -y @gatefare/mcp`
