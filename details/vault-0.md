## Overview

Vault-0 is an encrypted secret vault, agent monitor, and x402 wallet designed for OpenClaw. It handles 402 payment detection, EIP-3009 signing, and policy-gated auto-settlement for AI agent workflows.

## Features

- Encrypted secret vault for agent credentials
- Agent monitoring capabilities
- x402 wallet integration
- 402 payment detection
- EIP-3009 signing
- Policy-gated auto-settlement
