## Overview

TrustBoost is a PII sanitization layer for autonomous AI agent pipelines. It detects and redacts sensitive data before text reaches LLMs, with on-chain proof of sanitization verifiable on Solana.

## Features

- PII sanitization layer for autonomous AI agent pipelines
- Detects and redacts: emails, phone numbers, national IDs, private keys, financial data
- Protects text before it reaches LLMs
- Only PII sanitizer with on-chain proof of sanitization
- Verifiable at /verify/{anchor_tx} on Solana
- Supports: EN, ES (LATAM), PT (BR/PT), DE, JA
- Pay-per-call: $0.01 USDC on Base/Solana
- Bundle: $149/10k calls
- MCP server at /mcp
- Open source on GitHub
