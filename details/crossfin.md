## Overview

CrossFin is an x402 Agent Services Gateway focused on Korean market data. It provides the first financial data APIs in the x402 ecosystem, covering crypto premiums, stock indices, and exchange data for the Korean market.

## Features

- 15 paid Korean market data APIs
- Kimchi Premium, KOSPI, Bithumb, Upbit, Coinone, FX, headlines, trading signals
- First financial data APIs in the x402 ecosystem
- MCP server included

## Pricing

- Pay-per-call via x402 USDC

## Deployment

Cloud-hosted at crossfin.dev

## Integrations

- x402 payment protocol
- MCP server
