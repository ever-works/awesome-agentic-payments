## Overview

panevin-x402-api is a payment-gated web content extraction and AI processing API on Base mainnet. It offers 8 endpoints for various web processing tasks with x402 micropayments.

## Features

- Text extraction
- Link extraction
- Metadata extraction
- Markdown conversion
- AI summarization
- Translation
- Structured data extraction
- x402 payment gate on Base mainnet

## Pricing

$0.001–$0.008 USDC per call.
