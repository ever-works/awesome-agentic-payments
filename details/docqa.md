## Overview

DocQA is a document extraction verification API for AI agents. It takes extraction JSON plus the original document and returns validation results with confidence scores. It catches arithmetic errors, format inconsistencies, and cross-field mismatches that slip past schema validation.

## Features

- Document extraction verification
- Takes extraction JSON + original document
- Returns validation results with confidence scores
- Catches arithmetic errors, format inconsistencies, cross-field mismatches
- Gate mode returns pass/fail boolean for workflow integration
- x402 payment integration on Base
