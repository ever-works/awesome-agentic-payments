## Overview

BotIndex MCP is an MCP server for signal intelligence and trading data.

## Features

- 17 MCP tools
- Sports odds
- Crypto correlations
- Token graduations (Zora/Hyperliquid/Metaplex Genesis)
- DFS optimization
- Arbitrage detection
- 50 free requests per wallet
- Then x402 USDC on Base
- Usage: `npx botindex-mcp-server`
