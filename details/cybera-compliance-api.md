## Overview

CYBERA Compliance API is a crypto compliance suite for AI agents offering VASP address identification, risk scoring, and sanctions/mixer screening.

## Pricing

- $0.01 USDC per call on Base

## Features

- VASP address identification (20,468 addresses, 29 chains)
- Risk scoring (0-100 with signal detection)
- Sanctions/mixer screening (single + batch)
- Three endpoints

## Integrations

- USDC on Base for micropayments
- x402 payment enforcement
