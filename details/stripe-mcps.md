## Overview

stripe-mcps provides trust verification and AML sanctions screening before Stripe/x402 payments.

## Features

- Agent identity via ECDSA
- 75K+ sanctions entries (UK HMT + OFAC SDN)
- Behavioural spend limits
- OWASP MCP Security Cheat Sheet aligned
