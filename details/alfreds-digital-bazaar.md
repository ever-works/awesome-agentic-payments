## Overview

Alfred's Digital Bazaar is a collection of approximately 100 x402-paywalled API endpoints built by an AI agent, offering novelty and utility APIs such as fortune cookies, wallet roasts, crypto pickup lines, and token analysis.

## Pricing

- $0.10–$1.00 USDC per call on Base

## Features

- ~100 x402-paywalled API endpoints
- Fortune cookies, wallet roasts, crypto pickup lines, token analysis
- Built and operated by an AI agent
- No signup required

## Integrations

- USDC on Base for micropayments
- x402 payment enforcement
