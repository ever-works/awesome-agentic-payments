## Overview

Agent Commerce Desk provides Base wallet readiness, agent-commerce receipt, crypto market snapshot, OHLCV, and GitHub repo intelligence APIs for AI agents.

## Features

- Base wallet readiness
- Agent-commerce receipt
- Crypto market snapshot
- OHLCV data
- GitHub repo intelligence
- x402 v2 on Base mainnet
- Native USDC settlement

## Pricing

Endpoints range from $0.01-$2.00 per call.

## Deployment

Cloud-hosted at x402-wallet-readiness-service.vercel.app
