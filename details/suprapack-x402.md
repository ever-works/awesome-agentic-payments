## Overview

SupraPack x402 is a skill discovery API over a 531-skill curated bundle, designed for AI agents that need to discover and load specialized skills on-demand.

## Features

- 531-skill curated bundle
- Top matching skill results
- Full markdown content per skill
- Quality score
- Categories
- Source repo references
- Optional filters: min_quality, categories, limit
- Avoids bundling full 15 MB skill library

## Pricing

$0.01 USDC per call on Base mainnet.

## Deployment

Cloud-hosted API. Source: https://github.com/bshelby88/suprapack-x402
