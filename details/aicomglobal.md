## Overview

aicomglobal is a tri-protocol (MCP + A2A + x402) trust and clearing layer for AI agents on Base mainnet.

## Features

- aicom_verdict ($0.05 USDC): wallet-free, plain-HTTP-verifiable, Ed25519-signed, independently-recomputable trust + reliability verdict
- ERC-8004 responseHash/feedbackHash shape; verify offline at /.well-known/aicom-pubkey
- aicom_x402_route ($0.002): sub-cent x402 router, best live service for a need
- aicom_clear: signed clearing oracle for agent escrow
- Discovery + 78 deterministic agent tools free
- x402 manifest and agent-card available
