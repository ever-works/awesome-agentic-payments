## Overview

Verification Oracle provides independent verification of agent work products with wallet-signed attestations (EIP-191) plus cited coding research.

## Features

- Citation-support checks
- Data/schema validation
- Wallet-signed attestations (EIP-191)
- Cited coding research with signed attestation
- Free per-wallet quotas
- Free receipt-verification endpoint
- Bazaar discovery extension

## Deployment

Cloud-based on Base mainnet via CDP facilitator.

## Pricing

$0.10/research call, $0.25/verification USDC on Base mainnet. No API keys or signup required.
