## Overview

Kairos Lab x402 Workers provides 8 pay-per-call endpoints for AI agents on Solana mainnet.

## Features

- 8 pay-per-call endpoints
- Accepts both USDC and USDT (multi-token paywall)
- /audit-mcp ($0.05) — MCP server compliance + security audit
- /factcheck-fr ($0.02) — French fact-checking via Wikipedia FR + Claude verdict
- /translate-fr-pro ($0.03) — professional FR translation with glossaries + tu/vous register
- /legal-fr-quickcheck ($0.10) — French clause audit vs RGPD + Code civil + Code conso + Code travail
- /scrape-stealth ($0.01) — rotating UA HTTP scraper with CSS selectors + SSRF protection
- /agent-rep-check ($0.05) — Moltbook agent reputation snapshot
- /submolt-recommend ($0.02) — semantic submolt ranking for a topic
- /ai-act-mapping ($2.00) — EU AI Act Article 50 risk-tier mapping for SaaS products
- Self-hosted facilitator, multi-token settlement
- No API keys, no signup

## Pricing

- $0.01–$2.00 USDC/USDT per call depending on endpoint
