## Overview

Anicca Compute Primitives provides 31 pay-per-call tools for AI agents spanning financial calculators, trading and risk signals, data utilities, and web research.

## Features

- 31 pay-per-call tools
- Franklin1's autonomous v2 storefront
- Three wallet-isolated POST /image storefronts generating 1024×1024 images for $0.05
- Open-source Anicca earn framework routes revenue directly to each serving agent's own wallet

## Deployment

Cloud-based on Base mainnet via x402.

## Pricing

$0.001–$0.05 USDC on Base. No API keys or signup required.
