## Overview

CheapestInference is an LLM inference API with x402 pay-per-request in USDC on Base.

## Features

- OpenAI- and Anthropic-compatible API
- x402 pay-per-request in USDC on Base
- Keyless requests get a 402 with USDC pricing
- Serves open-weights models: Kimi K2.7, GLM 5.2, MiniMax M3, DeepSeek V4 Flash
- Agents can purchase flat-monthly unlimited subscription pools autonomously

## Pricing

Pay-per-request via x402 in USDC on Base; flat-monthly unlimited subscription pools available.
