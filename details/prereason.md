## Overview

PreReason is a financial context API that provides pre-analyzed market briefings for AI agents via x402 micropayments. It covers BTC, macro, and cross-asset regime signals with dual facilitator support.

## Features

- 17 pre-analyzed market briefings
- Covers BTC, macro, and cross-asset regime signals
- x402 pay-per-call: $0.01-$0.03 USDC on Base
- Dual facilitator: Coinbase CDP + Dexter
- Available via MCP server and REST API
- Open source on GitHub
- npm package: @prereason/mcp

## Pricing

- $0.01-$0.03 USDC per call on Base
