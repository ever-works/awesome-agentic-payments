## Overview

AgentRadar x402-trust is a pre-pay trust gate for x402 payments that scores payees before settlement.

## Features

- Score payee before settling a 402
- Block/warn on scam or low-trust wallets
- "Stripe Radar" for agent payments
- Library-agnostic fetch wrapper
- Zero runtime dependencies
- Powered by on-chain trust oracle
- ERC-8004 reputation
- Static analysis
- Scam database
