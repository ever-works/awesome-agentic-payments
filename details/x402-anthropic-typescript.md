## Overview

x402-anthropic-typescript is a TypeScript wrapper for transparent x402 HTTP 402 pay-and-retry with the Anthropic SDK. It uses a custom fetch wrapper passed to @anthropic-ai/sdk.

## Key Features

- TypeScript wrapper for Anthropic SDK
- Custom fetch wrapper passed to @anthropic-ai/sdk
- Transparent x402 HTTP 402 pay-and-retry
- ESM, fully typed
- Streaming-compatible

## Deployment

Self-hostable from GitHub repository.
