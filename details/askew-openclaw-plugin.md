# Askew OpenClaw Plugin

## Overview
OpenClaw plugin exposing paid and free Askew x402 endpoints as native skills.

## Features
- 5 paid + 3 free Askew x402 endpoints
- Thin Node bridge to `mcp.askew.network`
- Payments settle directly to Askew's wallet on Base
- No aggregator on the data path
- Open alternative to closed/curated x402 plugins
- Endpoints cover: DeFi yields across 5 chains, native-vs-liquid staking routing, agent-economy research search, security threat intel

## Installation
`openclaw plugins install @askew-network/openclaw-plugin`

## Pricing
Free and open source.

## Deployment
Client-side plugin, no server deployment required.
