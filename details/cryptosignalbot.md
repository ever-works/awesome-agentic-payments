## Overview

CryptoSignalBot is an x402-gated crypto volume anomaly scanner that identifies tokens with unusual trading volume patterns. It settles on Ethereum mainnet via the Primev facilitator.

## Features

- x402-gated crypto volume anomaly scanner
- Returns tokens with unusual trading volume patterns
- Compares current vs 30-day average volume
- $0.01 USDC per request on Ethereum mainnet
- Via Primev facilitator
- Python/FastAPI
- Live endpoint available
