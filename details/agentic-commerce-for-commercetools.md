## Overview

xpaysh reference TypeScript service implementing ACP, UCP, and AP2 protocols for commercetools. Includes RFC 9421 middleware (env-gated). Reference implementation, not production-hardened first-party path.

## Features

- Protocols: ACP, UCP, AP2
- Rails: x402, cards
- Type: TypeScript service, RFC 9421 middleware (env-gated)
- Maintainer: xpaysh (reference implementation)
