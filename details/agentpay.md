## Overview

AgentPay provides pay-per-call crypto data tools for AI agents using x402 payments on Stellar and Base networks.

## Features

- Token price data
- Whale activity tracking
- DeFi TVL metrics
- Fear & Greed index
- Dune query support
- Token security analysis
- Yield scanner
- Funding rates
- Budget-aware sessions
- MCP server integration via npx @romudille/agentpay-mcp

## Pricing

- $0.001–$0.005 USDC per call

## Deployment

Cloud-hosted API service.

## Integrations

- Stellar x402
- Base network
- USDC
- MCP (Model Context Protocol)
