## Overview

x402 Service Discovery API is an enriched directory of x402-payable services with trust signals, uptime tracking, and health metrics. It auto-scans ecosystem sources every 6 hours and provides an MCP server for agent discovery.

## Features

- Enriched directory of 251+ x402-payable services
- Trust signals, uptime tracking, latency metrics, health scores
- Auto-scans x402.org/ecosystem + awesome-x402 every 6 hours
- Companion MCP server with 6 tools: x402_discover, x402_trust, x402_health_check, x402_route, etc.
- Smart routing via RouteNet

## Pricing

- Pay-per-call via x402 USDC

## Deployment

Cloud-hosted on Render

## Integrations

- x402 payment protocol
- MCP server
- RouteNet smart routing
