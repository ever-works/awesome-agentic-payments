## Overview

TradeRoute is a crypto-trading data router for AI agents with 55 paid endpoints across multiple data categories, backed by 60+ upstream services.

## Features

- 55 paid endpoints
- Signals, market data, DEX routing
- Whale alerts
- Portfolio data
- News
- Identity
- Solana routing
- Bridges
- Onchain primitives
- ~40 keyless live data endpoints
- 60+ upstream services (CoinGecko, DefiLlama, DexScreener, Jupiter, Across, Warpcast, Web3.bio, ScamSniffer, Base/Solana RPCs)
- Trust-band routing
- Cross-agent cache

## Pricing

$0.001-$0.05 USDC per call on Base mainnet via Coinbase CDP facilitator.
