## Overview

DeFi Signal Agent provides real-time DeFi intelligence for AI agents, including pool risk scoring, whale alerts, and on-chain enrichment.

## Pricing

- 4 endpoints from $0.01–$0.10 USDC per call on Base Sepolia

## Features

- New pool risk scoring (0–10) on Base and Ethereum
- Solana whale alerts (>$100K)
- On-chain enrichment via Dune Analytics
- 4 endpoints
- Self-hostable

## Integrations

- USDC on Base Sepolia for micropayments
- x402 payment enforcement
- Dune Analytics
