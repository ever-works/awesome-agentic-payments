## Overview

OpenZeppelin Relayer x402 Facilitator is a Stellar x402 facilitator plugin for payment verification and settlement via OpenZeppelin Relayer.

## Key Features

- Stellar x402 facilitator plugin
- Payment verification and settlement
- Integration with OpenZeppelin Relayer
- Supports x402 payments on Stellar networks

## Deployment

Self-hostable plugin for OpenZeppelin Relayer.
