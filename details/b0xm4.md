## Overview

b0xM4 is a Meridian-powered Solana DLMM (Dynamic Liquidity Market Maker) screener that provides real-time DeFi analytics including TVL, volume, organic scores, smart wallet tracking, token safety, and yield rankings.

## Features

- Real-time TVL tracking
- Volume analytics
- Organic score
- Smart wallet tracking
- Token safety analysis
- Fee/TVL yield ranking
- 5 API endpoints
- Solana DLMM focus
- Meridian-powered

## Pricing

- $0.0001–0.0005 USDC per call

## Deployment

Cloud-hosted (Cloudflare Workers); payout on Solana
