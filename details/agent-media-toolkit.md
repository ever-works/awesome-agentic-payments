## Overview

Agent Media Toolkit is a hosted MCP server with 15 media and data tools for AI agents.

## Features

- 15 media & data tools: web search, news, page extraction, summarize, translate, moderate, script, text-to-voiceover, transcription, subtitles, short-form video clip discovery/editing
- Free tier over MCP for lighter tools
- Premium media pay-per-call via x402
- $0.02–$3.00 USDC on Base
- Streamable HTTP

## Pricing

- Free tier for lighter tools
- Premium media: $0.02–$3.00 USDC per call on Base via x402

## Deployment

Cloud-hosted MCP server (Streamable HTTP); self-hostable via GitHub.
