## Overview

glim.sh provides live data from Twitter, Reddit, the web, GitHub, Amazon, and YouTube for AI agents via 11 MCP tools.

## Deployment

Cloud-based on Base/Solana/Monad via x402 USDC micropayments.

## Pricing

$0.002–$0.015 USDC per call. No API keys, no scraping stack required.
