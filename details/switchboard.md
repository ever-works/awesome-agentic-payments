# switchboard

## Overview
Python middleware + on-chain escrow for agent payments.

## Features
- FastAPI/Flask `X402Middleware` server-side
- Gas budget tracker
- Reorg-safe nonce manager
- Solidity `AgentEscrow` with timeout/refund
- Protocol-agnostic substrate
- x402 + escrow shipping
- MPP/AP2 in flight

## Pricing
Free and open source.

## Deployment
Server-side Python middleware.
