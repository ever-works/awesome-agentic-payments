## Overview

x402search MCP is an MCP server for searching x402-enabled HTTP APIs.

## Features

- Search 14,000+ x402-enabled HTTP APIs by keyword
- Largest x402 API index available
- Agents pay $0.01 USDC per search on Base mainnet
- No API keys required
- Available on npm and PyPI
- Also live as ACP agent on Virtuals Protocol (ID 22531)

## Pricing

$0.01 USDC per search on Base mainnet.

## Deployment

npm/PyPI package (MCP server).
