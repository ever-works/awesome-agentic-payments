## Overview

AgentBridge is a pay-per-fetch gateway for Chinese web content (Xiaohongshu, Zhihu, etc.). It returns clean markdown content, settled in USDC on Base via x402.

## Key Features

- Pay-per-fetch gateway for Chinese web content
- Supports Xiaohongshu, Zhihu, and other Chinese platforms
- Returns clean markdown
- Settled in USDC on Base via x402

## Deployment

Self-hostable from GitHub repository.
