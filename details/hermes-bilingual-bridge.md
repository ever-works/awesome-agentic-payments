## Overview

Hermes Bilingual Bridge provides Chinese/Japanese patent and regulatory document translation plus summary extraction for cross-border research and compliance.

## Features

- Chinese/Japanese document translation
- Patent document translation
- Regulatory document translation
- Summary extraction
- x402 pay-per-call pricing

## Pricing

$0.03 USDC per call via x402.

## Deployment

Cloud-hosted API (Cloudflare Workers).
