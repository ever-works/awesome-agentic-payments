## Overview

x402engine is a pay-per-call API gateway offering 74 endpoints across multiple categories including LLMs, media generation, crypto data, web search, code execution, TTS, travel, and IPFS.

## Features

- 74 pay-per-call endpoints
- 44 LLM endpoints
- Image/video generation
- Crypto data
- Web search
- Code execution
- TTS (text-to-speech)
- Travel data
- IPFS
- Multi-chain support: USDC on Base, USDm on MegaETH, USDC on Solana
- Discovery: /.well-known/x402.json and /.well-known/agent.json
- MCP package available

## Pricing

Pay-per-call in USDC on Base, USDm on MegaETH, or USDC on Solana.

## Deployment

Cloud-hosted API gateway.
