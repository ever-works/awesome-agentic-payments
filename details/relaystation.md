## Overview

Relaystation is pay-per-call agent infrastructure with x402 micropayments.

## Features

- Durable file storage and handoff (batons)
- 150+ compute ops: PDF, data/CSV, image, audio/video, text
- Agent-to-human messaging
- E-signatures
- Identity verification
- Sanctions screening
- Agent contracts
- Sub-cent USDC/EURC pricing on Base
- No account required

## Pricing

- Sub-cent USDC/EURC per call on Base
- Pay per call via x402 micropayments

## Deployment

Cloud-hosted MCP server.
