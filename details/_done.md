## Overview

_done is a suite of x402 micropayment-gated utility APIs for AI agents.

## Features

- Web lookups
- Site analysis
- Data APIs
- Pay-per-call, no API keys or subscriptions
- Agents discover and pay per request via x402
- Base + Solana mainnet payment support

## Pricing

Pay-per-call via x402 micropayments.

## Deployment

Cloud-hosted at underscoredone.com

## Payment Networks

- Base mainnet
- Solana mainnet
