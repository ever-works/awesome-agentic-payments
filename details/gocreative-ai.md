## Overview

GoCreative AI provides 145+ pay-per-call APIs for AI agents across social enrichment, OSINT lookups, web scraping, image generation, and document intelligence.

## Features

- 145+ pay-per-call APIs
- Social enrichment
- OSINT lookups
- Web scraping
- Image generation
- Document intelligence
- USDC on Base via x402 (also Stripe)
- Free 5 calls/day per IP demo tier (no signup)
- Native MCP server
- Official GitHub Action
- 7 npm + 4 PyPI SDKs
- 20 HuggingFace Spaces
- OpenAPI specification
- x402 discovery at /.well-known/x402

## Pricing

- $0.001–$0.10 USDC per call
- Free tier: 5 calls/day per IP

## Deployment

Cloud-hosted on Base mainnet via x402 payment rail.
