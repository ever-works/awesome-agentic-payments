## Overview

Oromi Agent Services provides 25 pay-per-call endpoints for AI agents.

## Features

- Companies House lookups & business-name availability checks
- HM Land Registry property price trends & sold prices by postcode
- EPC ratings
- Current UK statutory rates (Bank Rate, tax/NI/VAT thresholds, minimum wage)
- PDF & page text extraction
- JSON Schema validation
- URL liveness
- Street-level crime context
- Food hygiene ratings
- Email/domain/EU-VAT/IBAN verification
- Web extract & robots.txt checks
- Crypto market context

## Pricing

- $0.002–$0.05 USDC on Base via CDP facilitator
- No API keys, no signup
