## Overview

swornly provides deterministic, signed-receipt tools for AI agents. Every answer returns an HMAC-signed, re-verifiable receipt.

## Features

- HMAC-signed, re-verifiable receipts
- /dry-run/command: checks if shell/git command is destructive + blast radius before execution
- /diff/mcp-schema: breaking vs non-breaking MCP tools/list changes
- /snapshot/tool-contract: stable tools/list fingerprint for contract pinning
- /convert: Markdown to PDF
- /receipts/verify: free receipt verification
