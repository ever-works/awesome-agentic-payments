## Overview

x402-signature-service provides e-signatures for AI agents.

## Features

- Send one PDF to one email recipient for simple electronic signature (powered by Documenso)
- Track completion with a one-time bearer token
- Download the signed PDF
- Closes the human-sign-off gap for contract/NDA workflows
- SSRF-guarded document fetching
- Tokens stored as hashes

## Pricing

- $0.50 USDC per request on Base (x402 exact scheme, v1-compatible 402 body)
- No API keys, no signup
