## Overview

Social Intel provides Instagram influencer search API for AI agents via x402 USDC micropayments.

## Features

- Search by niche, country, demographics, or follower count
- Returns usernames, bios, follower counts, business categories, and public business emails
- Single-profile lookup at $0.01; full search $0.50–$1.30 (100 leads)

## Deployment

Cloud-based on Base, Solana, Polygon, Arbitrum via x402 USDC.

## Pricing

USDC on multiple chains. No signup required.
