## Overview

KnowMint is an open-source knowledge marketplace with an x402 payment gate on Solana. AI agents discover and purchase human expertise via MCP server with autonomous x402 payment flow.

## Features

- Open-source knowledge marketplace
- x402 payment gate on Solana
- AI agents discover and purchase human expertise
- MCP server with autonomous x402 payment flow
- No accounts required
