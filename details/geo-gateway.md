## Overview

geo-gateway is a pay-per-call Mapbox geospatial proxy API for AI agents, offering directions, isochrones, geocoding, map matching, route optimization, and distance matrices.

## Pricing

- $0.002–$0.0635 USDC per call on Base

## Features

- Directions (walking/cycling/driving)
- Isochrones (reachable area polygons)
- Geocoding (forward + reverse)
- Map matching (snap GPS traces to roads)
- Route optimization (multi-stop TSP)
- Distance matrices
- Pre-payment validation (bad requests never charged)

## Integrations

- USDC on Base for micropayments
- x402 payment enforcement
- Mapbox
