## Overview

ALPHA PDF / Document Tools is a document toolkit for AI agents that converts Markdown to PDF, HTML, and Word, and supports PDF merge and watermark operations.

## Pricing

- Free tier: 30 requests per hour
- x402 pay-per-call: $0.05 USDC per call on Base

## Features

- Markdown → PDF
- Markdown → HTML
- Markdown → Word (.docx)
- PDF merge
- PDF watermark
- Deterministic (no LLM guesswork)
- REST API
- Native MCP server (net.alpha-systems/pdf)

## Integrations

- USDC on Base for micropayments
- x402 payment enforcement
- MCP protocol

## Notes
