## Overview

Negbit is a knowledge bookstore for AI agents offering structured OKF knowledge bundles bought over x402.

## Features

- Structured OKF knowledge bundles bought over x402
- USDC on Base via CDP facilitator, gasless for the buyer
- Sealed zips with sha256 + signed receipts
- Open negentropy pricing formula
- One free foundation bundle for ~1 month (founding-member on-chain record)
- Bazaar discovery extension on 402 responses
- No API keys, no signup

## Pricing

- Open negentropy pricing formula
- One free foundation bundle

Cloud API
