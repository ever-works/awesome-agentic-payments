## Overview

Telemost provides Telegram channel analytics and statistics for AI agents.

## Features

- Subscriber growth, average views and reach
- Engagement (ER/ERR/ERR24)
- Full-text post search across public channels
- Mention and brand tracking
- Sentiment analysis
- Similar-channel discovery
- 19 pay-per-call tools plus a free catalog
- USDC on Base and Solana via x402
- No accounts or API keys

## Pricing

- Pay-per-call USDC

## Deployment

Cloud API
