## Overview

presidio-hardened-x402 is pre-signing hardening middleware for agent x402 payments.

## Features

- PII detection and redaction over payment metadata
- Spending-policy limits
- Replay detection
- All checks run before the payment is signed
- Fail-closed design
- Backed by a labelled corpus and a published study

## Pricing

Open source, free to use.
