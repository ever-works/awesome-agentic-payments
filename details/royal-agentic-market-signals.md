## Overview

Royal Agentic Market Signals provides paid x402 market intelligence endpoints for AI agents on Base mainnet.

## Features

- NFT collection signal lookup via POST /api/nft-signal
- Equity ticker analysis via POST /api/analyze-ticker
- Settled paid calls
- Bazaar discovery metadata

## Pricing

Paid via USDC on Base mainnet.

## Integrations

- USDC payments route through Coinbase CDP facilitator
- x402 payment protocol on Base (eip155:8453)
- NFT Alpha endpoint: https://nft-alpha-x402.fly.dev/api/nft-signal
- TradingAgents endpoint: https://tradingagents-x402.fly.dev/api/analyze-ticker
