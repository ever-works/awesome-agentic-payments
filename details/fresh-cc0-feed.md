## Overview

Fresh CC0 Feed is a pay-per-call feed of works freshly dedicated to the public domain (CC0/Unlicense), aggregated from GitHub and Zenodo into a single schema with reproducible provenance.

## Features

- Feed of CC0/Unlicense dedicated works
- Aggregated from GitHub and Zenodo
- Reproducible provenance with verbatim LICENSE SHA-256
- Rights-clean assets, code, and datasets for AI agents
- Disclosure-ready proof

## Pricing

$0.02 USDC per call on Base mainnet, no API key required.

## Integrations

- x402 payment protocol on Base (eip155:8453)
- Sample endpoint available
- llms.txt documentation available
