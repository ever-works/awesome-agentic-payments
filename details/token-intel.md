## Overview

Token Intel provides Solana token due-diligence for AI agents.

## Features

- One call fuses on-chain safety signals (mint/freeze authorities, holder concentration, dev holdings)
- Market data and rug indicators from three independent sources (Jupiter, DexScreener, RugCheck incl. LP-lock depth)
- Cross-checks sources for disagreement red flags
- Synthesized 0–100 risk verdict
