## Overview

SwapTitan is a no-KYC cross-chain crypto swap API for AI agents.

## Features

- 1288+ assets aggregated across 3 providers (ChangeNOW, SimpleSwap, Heleket)
- H2H Privacy Routing — pipes swaps through Monero for unlinkable source/destination chains
- 10 MCP tools: swap_quote, swap_create, swap_status, get_prices, get_assets, ai_chat (Llama 3.3 70B), check_portfolio, rug_check, create_wallet, set_price_alert
- On-chain x402 verification with 10-min TX freshness + KV replay protection

## Pricing

- $0.02 USDC on Base per MCP call (2 free/day per IP)
- $0.05 per swap_create
- €49.99/mo Agent Tier for unlimited via X-License-Key header
