## Overview

Gotobi Calendar API provides Japanese FX gotobi date intelligence for trading agents, including holiday-aware USD settlement day detection and monthly schedules.

## Pricing

- $0.01 USDC on Base and Solana

## Features

- Holiday-aware USD settlement day detection
- Next-date lookup
- Monthly schedules

## Integrations

- USDC on Base and Solana for micropayments
- x402 payment enforcement
