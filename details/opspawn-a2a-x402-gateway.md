## Overview

OpSpawn A2A x402 Gateway is a multi-chain Agent-to-Agent gateway that integrates x402 payments with the Google A2A protocol, supporting Base, SKALE, and Arbitrum blockchains.

## Features

- Multi-chain A2A gateway
- x402 payment integration
- Google A2A protocol support
- Base, SKALE, Arbitrum chain support
- Multi-chain agent commerce
