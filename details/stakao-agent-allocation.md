## Overview

Stakao Agent Allocation Analysis provides informational Bittensor allocation analysis API for AI agents, paid with x402 v2 USDC on Base.

## Features

- Walletless model portfolio snapshots
- Wallet-specific preflight flows
- OpenAPI
- Read-only MCP
- llms.txt discovery

## Deployment

Cloud-based on Base mainnet via x402 v2 USDC.
