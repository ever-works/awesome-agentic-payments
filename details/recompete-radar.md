## Overview

Recompete Radar provides source-linked U.S. federal contract award expiration evidence from USAspending.gov for research agents.

## Features

- Returns recorded period-of-performance end dates
- Agency and recipient context
- Obligations data
- Official award links
- $0.03 USDC per successful request
- Settles on Base or Solana via x402 v2
- Reports public records; does not predict recompetes

## Integrations

- OpenAPI spec available
- x402 discovery at `.well-known/x402`
- llms.txt available

## Pricing

- $0.03 USDC per successful request
- Settlement: USDC on Base or Solana via x402 v2
