## Overview

agentmail provides OFAC sanctions screening, transaction risk scoring, and Know-Your-Agent verification before an agent pays.

## Features

- Screen counterparty wallet, name, or country against OFAC SDN list (782 crypto wallets, 19,086 SDN entries, 16 embargoed jurisdictions)
- Returns allow/review/decline decision
- Compatible with x402, AP2, and AgentKit
- Free tier, no API key
- MCP + HTTP + CLI interfaces
- MIT license

## Pricing

Free tier available; paid tiers not specified.
