# @chain-ops/agent-sdk

## Overview
One-line SDK combining x402 payments with ERC-8004 agent identity.

## Features
- x402 payments (V1 + V2)
- ERC-8004 agent identity
- `agent.pay(url)` attaches identity, signs EIP-712, checks counterparty trust, updates reputation
- Single-call settlement
- Configurable price cap
- Configurable min counterparty score
- USDC on Base

## Pricing
Free and open source.

## Deployment
Client-side SDK, no server deployment required.
