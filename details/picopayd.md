## Overview

PicoPayd is a pay-per-call API marketplace for AI agents, offering utility APIs priced from $0.001 to $0.01 per call. It runs on Cloudflare Workers and settles payments via USDC on Base mainnet.

## Features

- Pay-per-call API marketplace for AI agents
- Utility APIs: email/phone/IBAN validation, DNS, WHOIS, image conversion, QR, HTML-to-PDF
- Pricing: $0.001-$0.01 per call
- Deployed on Cloudflare Workers
- Base mainnet USDC settlement

## Pricing

- $0.001-$0.01 USDC per call depending on API

## Deployment

Cloudflare Workers

## Integrations

- x402 payment protocol
- Base mainnet USDC
