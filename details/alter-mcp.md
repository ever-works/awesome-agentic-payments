## Overview

ALTER MCP provides verified human identity infrastructure for AI agents using a 33-trait psychometric engine.

## Features

- 33-trait psychometric engine
- Belonging probability scoring
- Trait alignment analysis
- Ed25519-signed identity vectors
- Identity income via x402 USDC
- Tiered per-query pricing (L0 free → L5 $0.50)
- Identity holders earn 75% per verified query
- 24 free tools, 40 invokable at launch
- 100 free queries/bot
- SDK: @truealter/sdk
