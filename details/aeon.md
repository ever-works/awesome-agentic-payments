## Overview

Aeon is an autonomous agent framework that runs unattended on GitHub Actions. Its skills can hit x402-gated endpoints and settle USDC through the Bankr gateway, letting scheduled agents make paid API calls and on-chain actions with no human in the loop.

## Features

- Autonomous agent execution on GitHub Actions
- x402-gated endpoint access
- USDC settlement via Bankr gateway
- Scheduled agent operation
- No human intervention required
- MIT licensed

## Pricing

Free and open source under the MIT license.

## Deployment

Self-hosted via GitHub Actions.
