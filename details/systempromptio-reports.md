## Overview

systemprompt.io reports is a paid MCP server providing decision-ready EU AI Act compliance reports for agents.

## Features

- eu_ai_act_compliance tool ($1.50): deterministic Annex III classification, article-by-article obligation gaps, Annex IV documentation checklist, remediation plan sequenced against the 2 Aug 2026 deadline
- info tool is free
- USDC on Base mainnet (eip155:8453) via x402 settled through the CDP facilitator
- Card payment via Stripe checkout
- No account or API key required
- Streamable HTTP
- Discovery free, prices in tool descriptions and _meta.x402
- Inputs validated before payment so invalid calls are never charged
- New report tools appear in tools/list as they launch

## Pricing

- info: free
- eu_ai_act_compliance: $1.50

## Deployment

Cloud-hosted MCP server (Streamable HTTP).
