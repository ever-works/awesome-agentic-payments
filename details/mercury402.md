## Overview

Mercury402 is a pay-per-call U.S. Treasury and macro data API that uses x402 for USDC micropayments on Base.

## Features

- FRED indicators
- Yield curves
- GDP data
- U.S. Treasury data
- Macro economic data

## Pricing

USDC micropayments per call on Base.

## Deployment

Cloud-hosted, pay-per-call via x402.
