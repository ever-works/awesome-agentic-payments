## Overview

Spraay MCP Server is an MCP server for multi-chain DeFi payments with x402 support.

## Features

- 60+ MCP tools
- Multi-chain DeFi payments
- Batch sends
- Payroll
- Token swaps
- Bridge
- Escrow
- AI inference
- Robot Task Protocol (RTP)
- 76+ x402 endpoints across 13 chains (Base, Ethereum, Solana, Bitcoin, + 9 more)
- Pricing: $0.005–$0.25 USDC

## Pricing

$0.005–$0.25 USDC.
