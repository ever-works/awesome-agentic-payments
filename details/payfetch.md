# payfetch

## Overview
Non-custodial paying-fetch client for agents.

## Features
- TypeScript library
- CLI
- MCP server
- Operator-owned spending policy
- Hard per-call/per-day/per-host caps
- Allow/deny lists
- Approval threshold
- Optional pre-pay endpoint-reliability checks
- Optional pre-pay token-safety checks
- Append-only local receipt for every attempt, including refusals
- Agent cannot raise its own limits
- USDC on Base
- MIT license

## Pricing
Free and open source (MIT).

## Deployment
Client-side library, CLI, and MCP server.
