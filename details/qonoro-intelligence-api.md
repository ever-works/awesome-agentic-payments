## Overview

Qonoro Intelligence API provides x402-native intelligence APIs for AI agents and business workflows on Base mainnet.

## Features

- /v1/company/research: company intelligence
- /v1/competitors/analyze: business competitor analysis
- /v1/sales-signals/find: sales signal detection
- Structured JSON outputs with source-backed evidence and confidence scores
- Pricing by endpoint via /v1/pricing/{agent_id}
- x402-native on Base mainnet

## Pricing

- Pricing by endpoint via /v1/pricing/{agent_id}

## Deployment

Cloud-hosted on Base mainnet via x402 payment rail.
