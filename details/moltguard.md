## Overview

MoltGuard is an all-in-one trust and integrity API for the x402 agent economy. It provides agent trust scoring, Sybil detection, Polymarket integrity checks, and Verifiable Credentials, built on Base mainnet.

## Features

- Agent trust scoring (0–100)
- Sybil detection with funding cluster analysis
- Polymarket integrity checks
- Ed25519-signed Verifiable Credentials
- Built on Base mainnet with Blockscout
- ERC-8004 integration
- MolTrust DID integration
- $0.005–$0.05 USDC
- 7 MCP tools available
- Open source on GitHub
