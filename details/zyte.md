## Overview

Zyte is a web scraping platform that supports x402 payments, enabling AI agents to pay for web scraping services via micropayments.

## Features

- Web scraping with x402 payments
- Scraping infrastructure for AI agents
- x402 micropayment settlement

## Pricing

- Pay-per-use via x402

## Deployment

Cloud-hosted at zyte.com

## Integrations

- x402 payment protocol
