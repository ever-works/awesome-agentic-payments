## Overview

Mailcheck API provides email validation for AI agents, checking syntax, MX records, disposable domains, free providers, role-based addresses, and suggesting typos.

## Pricing

- $0.01 USDC on Base

## Features

- Syntax validation
- MX records check
- Disposable domain detection
- Free provider check
- Role-based address detection
- Typo suggestion

## Integrations

- USDC on Base for micropayments
- x402 payment enforcement
