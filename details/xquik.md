## Overview

Xquik provides real-time X (Twitter) data API with 7 pay-per-use endpoints on x402.

## Endpoints

- Tweet lookup
- Tweet search
- User lookup
- Follower check
- Article extraction
- Media download
- Trends

## Deployment

Cloud-based on Base mainnet via x402 USDC micropayments.

## Pricing

Pay-per-use USDC micropayments on Base. No accounts or subscriptions required.
