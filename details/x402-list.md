## Overview

x402 List is an agent-first directory of x402 API services with live uptime monitoring and machine-readable discovery for AI agents.

## Features

- Live uptime monitoring
- Machine-readable discovery for AI agents
- JSON API
- OpenAPI 3.1
- llms.txt
- Per-service endpoints, pricing, response time, and uptime charts

## Pricing

Free directory service.

## Deployment

Cloud-hosted at x402-list.com
