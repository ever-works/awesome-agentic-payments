## Overview

EDGAR Intelligence API provides SEC EDGAR corporate filing intelligence for AI agents, including company search, filing history, and XBRL financial facts.

## Pricing

- $0.01 USDC per call on Base

## Features

- Company search with ticker/CIK
- Filing history by type (10-K/10-Q/8-K/20-F)
- XBRL financial facts with YoY growth rates
- Revenue, net income, EPS, assets

## Integrations

- USDC on Base for micropayments
- x402 payment enforcement
