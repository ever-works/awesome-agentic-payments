## Overview

SmartFlow Mapper API is a JSON REST API exposing over 22,251 catalogued x402 endpoints with uptime, payment-success, and facilitator metadata.

## Features

- 22,251+ catalogued x402 endpoints
- Uptime metadata
- Payment-success metadata
- Facilitator metadata
- Free tier: 100 req/day
- Paid bulk export

## Pricing

Free tier (100 req/day) + paid bulk export.
