## Overview

Base Token Safety Scanner is a free API that analyzes Base chain ERC-20 tokens for security risks.

## Features

- Analyzes Base chain ERC-20 tokens
- Rug pull risk detection
- Honeypot detection
- Ownership issue detection
- Security flag analysis
- Risk score with detailed flag breakdown
- Built for AI agents and DeFi traders

## Pricing

Free API.

## Deployment

Cloud-hosted at base-token-scanner.onrender.com
