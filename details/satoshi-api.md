## Overview

Satoshi API provides Bitcoin fee market, next-block mining, and transaction intelligence for agents and apps via x402 pay-per-call endpoints on Base.

## Features

- Bitcoin fee market data
- Next-block mining intelligence
- Transaction intelligence
- x402 pay-per-call endpoints on Base
