## Overview

SwarmX is a multi-agent AI orchestration platform with native x402 micropayments on Solana. It offers 49 endpoints, 39 MCP tools, dual LLM support (Gemini + OpenAI), knowledge/RAG with pgvector, and an ElizaOS v2 plugin.

## Features

- Multi-agent AI orchestration
- Native x402 micropayments on Solana
- 49 API endpoints
- 39 MCP tools
- Dual LLM (Gemini + OpenAI)
- Knowledge/RAG with pgvector
- ElizaOS v2 plugin
- Priced at $0.001–$5 per call USDC

## Pricing

$0.001–$5 per call USDC.
