## Overview

Hyperbolic x402 Chat API is an LLM Pay-per-Request Chat API that integrates x402 payments. It enables pay-per-request access to LLM chat services with USDC settlement.

## Key Features

- LLM Pay-per-Request Chat API
- x402 payment integration
- USDC settlement
- Pay-per-request pricing model

## Deployment

Self-hostable from GitHub repository.
