# x402-receipts

## Overview
Signed proof-of-delivery receipts for x402 sellers.

## Features
- Verify settlement on-chain
- Merkle-batch receipt roots
- Anchor receipt roots via EAS on Base
- Notify layer for human-readable alerts
- Alert channels: email HTML, Slack, Discord, Telegram, webhook
- Zero deps beyond viem
- 178 tests
- Apache-2.0 license
- Running in production

## Pricing
Free and open source (Apache-2.0).

## Deployment
Server-side library.
