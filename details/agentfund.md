## Overview

AgentFund provides fundraising infrastructure for AI agents on Solana, enabling on-chain identity registration, campaign launches, x402-based donations, milestone voting, and reputation building.

## Features

- On-chain agent identities
- Campaign launches
- Donate via x402 (payment is the auth, no API keys)
- Vote on milestone releases
- On-chain reputation building
- Program-derived escrow for funds
- Live on devnet with real settled x402 USDC donations
