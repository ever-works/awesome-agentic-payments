## Overview

x402 Entity-ID Resolver is a canonical cross-registry entity-ID resolver for AI agents that fuses verified IDs across multiple registries.

## Features

- Cross-registry entity-ID resolution for companies and crypto names/tickers
- Fused IDs from: SEC CIK + ticker, GLEIF LEI, Wikidata QID, CoinGecko slug
- Each ID tagged with sources that agreed for verifiability
- $0.005 USDC per call on Base mainnet
- Gasless (EIP-3009)
- No API key required
- v2 with Bazaar discovery extension
- OpenAPI specification
- llms.txt for agent discovery
