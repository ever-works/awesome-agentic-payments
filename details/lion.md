## Overview

LION offers keyless data and compliance tools for AI agents, accessible via x402 USDC micropayments on Base. The platform provides 20 tools spanning sanctions screening, token risk, tax validation, firmographics, and financial data.

## Features

- 20 keyless data & compliance tools for AI agents
- x402 USDC micropayments on Base
- OFAC sanctions screening
- On-chain token risk assessment
- EU VAT validation
- Firmographics + SEC financials
- CPG/retail prices
- Ed25519-attested responses for offline verification
- No API key, no signup required
- MCP endpoint available

## Pricing

- Paid per-call via x402 USDC micropayments on Base
