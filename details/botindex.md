## Overview

BotIndex is an AI-native signal intelligence API with 17 x402 endpoints across 7 domains. It covers sports odds, crypto correlations, token graduations, DFS optimization, arbitrage detection, and agentic commerce comparison. It offers 50 free premium requests per wallet before paid tier.

## Features

- AI-native signal intelligence API
- 17 x402 endpoints across 7 domains
- Sports odds
- Crypto correlations
- Token graduations (Zora/Hyperliquid/Metaplex Genesis)
- DFS optimization
- Arbitrage detection
- Agentic commerce comparison
- 50 free premium requests per wallet
- Then $0.01–$0.50 USDC on Base
- MCP server with 17 tools
- Open source on GitHub
- npm package: botindex-mcp-server
