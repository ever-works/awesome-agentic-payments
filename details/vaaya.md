## Overview

Vaaya is an agent payment system delivered as an MCP server that enables agents to purchase various services pay-per-call over x402.

## Features

- Media/video generation
- Product demo rendering
- Web search & scraping
- Deep research
- Lead enrichment
- Code sandboxes
- Browser automation
- Pay-per-call over x402 (USDC on Base) or MPP
- Payment is the auth, no API keys
- Remote MCP at https://vaaya.ai/mcp
- npx -y @vaaya/mcp for stdio

## Pricing

Pay-per-call via x402 on Base USDC; pricing varies by service.

## Deployment

Remote MCP server and stdio installation via npm.
