## Overview

Zero is an MCP connector that lets an AI discover and pay for thousands of external tools, APIs and services at runtime via x402/MPP.

## Features

- Discover a capability, inspect it, call it, and pay per use
- No API keys, no signup
- Free to use ($5 of credit to start)
- Paid calls are usually pennies
- Ships a CLI
- Ships a Claude Code plugin

## Pricing

- Free to use ($5 of credit to start)
- Paid calls usually pennies
- Pay per use via x402/MPP

## Deployment

Cloud-hosted MCP connector.
