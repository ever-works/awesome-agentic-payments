## Overview

Recall Kitchen is an MCP server for searching product recalls with x402 payment support.

## Features

- Search food, product, and vehicle recalls
- Accepts x402 payments
- No account required
- $0.025 USDC on Base per request

## Pricing

$0.025 USDC on Base per request.

## Deployment

MCP server (documentation at recallkitchen.com/docs/#mcp).
