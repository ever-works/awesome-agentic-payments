## Overview

Scout MCP performs multi-source search across code, academic, social, and community platforms, returning structured JSON from a single call.

## Pricing

- From $0.01 USDC on Base
- $0.25 for aggregated reports

## Features

- Multi-source search (code, academic, social, community platforms)
- Structured JSON output

## Integrations

- USDC on Base for micropayments
- x402 payment enforcement
