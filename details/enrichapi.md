## Overview

EnrichAPI is a B2B lead intelligence API for AI sales agents. It accepts a company URL and returns structured JSON with tech stack, growth signals, ICP fit score, pain hypothesis, and personalized outreach angle.

## Features

- B2B lead intelligence API for AI sales agents
- POST a company URL, get structured JSON
- Tech stack, growth signals, ICP fit score, pain hypothesis
- Personalized outreach angle
- $0.01 USDC/call via x402 (no API key needed)
- Subscription tiers via Stripe
- Built by an autonomous AI agent
- Open source on GitHub
- Docs available
