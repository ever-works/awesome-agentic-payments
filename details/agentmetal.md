## Overview

AgentMetal rents a real Linux VPS to AI agents with HTTP 402 payment integration (x402 on Base). Agents can provision, extend, and destroy VPS instances without creating an account.

## Features

- HTTP 402 → pay USDC (x402 on Base) or card → SSH in under 60s, no signup
- Provision/extend/destroy VPS instances
- Root `exec` over SSH
- Per-box firewall
- Add-on block storage
- Pricing from $1.20/day with 20 TB egress included
- Self-hosted facilitator (no CDP)
- Local `npx @agentmetal/mcp` (13 tools, signs from your wallet)
- Read-only remote MCP at https://api.agentmetal.dev/mcp
