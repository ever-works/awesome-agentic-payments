## Overview

AgentBanks is Base blockchain data and agent payment infrastructure designed for AI agents. It combines free public data with paid premium endpoints, using B20-native memo payments for on-chain order receipts.

## Features

- Free: live gas prices, agent registry
- Paid: ETH/BTC/VIRTUAL/AERO prices + Base DeFi TVL ($0.003 USDC)
- Paid: private AI inference ($0.01 USDC)
- B20-native memo payments — on-chain order receipts
- No API key required
- Base mainnet
- B20 API documentation available

## Pricing

- Free tier: live gas prices, agent registry
- Paid: $0.003 USDC for ETH/BTC/VIRTUAL/AERO prices + Base DeFi TVL
- Paid: $0.01 USDC for private AI inference

## Deployment

Cloud-hosted on Vercel
