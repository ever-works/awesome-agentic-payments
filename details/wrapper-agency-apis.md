## Overview

wrapper-agency offers a suite of 8 pay-per-call utility APIs settled in USDC on Base via x402, with a free tier and one API key for all services.

## Features

- Historical FX rates
- Color conversion
- Timezone/DST
- Fake/mock data
- Cron explainer
- QR codes
- Data-format conversion
- Encode/hash
- Free tier available
- One API key for all services

## Pricing

Free tier plus pay-per-call USDC on Base via x402.

## Deployment

Cloud-hosted APIs.

## Integrations

- x402 payment protocol
- Base network (USDC)
