## Overview

Superhighway is a live web search API that uses x402 pay-per-call micropayments on Base.

## Features

- Search, news, images, scrape, and research capabilities
- $0.001 per call on Base
- MCP server: npx -y superhighway-mcp
- No signup required
- Autonomous agent discovery and calling
- Wallet pays directly

## Pricing

$0.001 per call on Base (x402 micropayments).

## Deployment

Cloud-hosted API with MCP server integration.
