## Overview

RepoPulse provides a deterministic 0–100 health score for any public GitHub repository with a nine-signal breakdown and A–F grade.

## Features

- 0–100 health score for public GitHub repositories
- Nine-signal breakdown: commit recency, release cadence, issue hygiene, PR flow, bus factor, CI, tests, docs, dependency freshness
- A–F grade assignment
- Flag indicators
- Bazaar-discoverable
- MCP-ready
