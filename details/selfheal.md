## Overview

SelfHeal is a self-healing API proxy for AI agents with x402 outcome-based pricing.

## Features

- Agents route HTTP calls through the proxy
- Successes pass through free
- Failures trigger x402 payment for LLM-powered error diagnosis + response normalization
- $0.001-$0.005 USDC on Base
- Charged only on successful heal
- Published SDKs on npm and PyPI with native x402 support

## Pricing

$0.001-$0.005 USDC on Base, charged only on successful heal.

## Deployment

Cloud-hosted API proxy at selfheal.dev
