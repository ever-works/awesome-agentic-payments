## Overview

Pyrimid is an agent commerce protocol for x402-style USDC payments on Base.

## Features

- On-chain vendor/product registry
- Payment router
- Affiliate attribution
- MCP endpoint
- Live catalog API for agent-discoverable paid services

## Pricing

Not specified.

## Deployment

On-chain on Base network.

## Integrations

- x402 payment protocol
- Base network (USDC)
- MCP (Model Context Protocol)
