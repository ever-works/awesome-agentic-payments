## Overview

DPX Settlement Protocol is an MCP server for institutional cross-border settlement on Base mainnet.

## Features

- 23 MCP tools
- Institutional cross-border settlement on Base mainnet
- 9-layer Stability Oracle (climate, macro, FX, ESG, supply chain, earth systems)
- 23 x402 intelligence endpoints ($0.15–$0.75 USDC)
- ESG scoring
- Compliance screening
- USDC settlement
- MiCA-aligned, GENIUS Act compatible
- Usage: `npx @untitledfinancial/dpx-mcp`

## Pricing

$0.15–$0.75 USDC per x402 intelligence endpoint.

npm package (MCP server); docs at docs.untitledfinancial.com.
