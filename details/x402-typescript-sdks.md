## Overview

Official TypeScript SDKs for the x402 protocol from the x402 Foundation. These SDKs provide client, server, facilitator, and MCP helpers for integrating x402 payments into JavaScript and TypeScript applications.

## Key Features

- Official TypeScript client for x402 payments
- Server-side payment verification helpers
- Facilitator integration utilities
- MCP (Model Context Protocol) helpers
- Part of the x402 Foundation monorepo

## Deployment

Published as npm packages, can be self-hosted.
