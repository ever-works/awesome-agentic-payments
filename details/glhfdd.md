## Overview

GLHFDD provides AI-powered text analysis, code analysis, and data transformation APIs built by a self-hosted AI agent via x402 protocol on Base mainnet.

## Endpoints

- POST /analyze/text ($0.01)
- POST /analyze/code ($0.02)
- POST /transform/data ($0.005)

## Deployment

Self-hosted on Base mainnet via x402.

## Pricing

Pay-per-call USDC micropayments on Base. No API keys, no signup required.
