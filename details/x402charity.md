## Overview

x402charity is open-source middleware for automatic micro-donations via x402, enabling charitable giving to be embedded into any payment flow.

## Features

- Drop-in Express/Next.js middleware
- Triggers USDC charity donations on every user action (API call, trade, game move)
- npm package available
- CLI available
- Vercel-deployable server
- Built-in dashboard
- Embed charitable giving into trades, API calls, subscriptions

## Pricing

$0.0001 USDC per event on Base mainnet.
