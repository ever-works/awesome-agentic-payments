## Overview

x402-proxy is a CLI tool that acts as curl for x402 paid APIs. It auto-pays HTTP 402 responses with USDC on Base and Solana, and includes an MCP stdio proxy for AI agents.

## Features

- Auto-pays HTTP 402 responses with USDC
- Supports Base and Solana networks
- MCP stdio proxy for AI agents
- Installable via `npx x402-proxy`

## Pricing

Open source, free to use.

## Deployment

Local CLI tool via npm
