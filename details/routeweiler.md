# Routeweiler

## Overview
Python micropayment client for autonomous agents.

## Features
- Auto-handles HTTP 402 across x402, L402, MPP-Tempo, and Stripe SPT
- Enforces policy & budget
- Produces payment traces for auditing

## Pricing
Free and open source.

## Deployment
Client-side Python SDK.
