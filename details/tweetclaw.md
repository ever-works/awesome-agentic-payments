## Overview

TweetClaw is an OpenClaw/MCP plugin for accessing real-time X (Twitter) data via x402 payments.

## Features

- OpenClaw/MCP plugin for Xquik's real-time X (Twitter) data
- 7 pay-per-use endpoints via MPP/x402
- Tweet lookup
- Search
- User lookup
- Follower check
- Article
- Media download
- Trends

## Pricing

Pay-per-use via MPP/x402.

## Deployment

MCP plugin at https://xquik.com/mcp.
