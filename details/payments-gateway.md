# payments-gateway

## Overview
Brand-neutral Fastify payments engine supporting x402 USDC paywalls and Monero/Zcash view-key payment watching.

## Features
- x402 USDC paywalls
- Auto-selects Coinbase CDP facilitator when keys present
- Bazaar discovery on every route
- Monero/Zcash view-key payment watching
- Webhooks
- Prepaid credit meters topped up via x402 or native XMR/ZEC
- Embeddable REST plugin
- MCP tool registrar
- Standalone bins
- Custom branding, prices, and webhook headers
- MIT license
- Production-extracted from seneschal.space
- Built on x402-server-kit

## Pricing
Free and open source (MIT).

## Deployment
Self-hosted Fastify payments engine.
