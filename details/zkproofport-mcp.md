## Overview

ZKProofport MCP is a zero-knowledge identity proof MCP server for AI agents.

## Features

- Zero-knowledge identity proofs
- Coinbase KYC proofs
- Country proofs
- Google OIDC proofs
- Workspace proofs
- MS 365 proofs
- No personal data revealed
- AWS Nitro Enclave TEE proving
- ERC-8004 registered (token ID 25331)
- x402 USDC payments on Base
- NPM: @zkproofport-ai/mcp
