## Overview

Stelar Digital x402 API provides pay-per-call market data and grid-trading parameters for AI agents on Algorand mainnet via the GoPlausible facilitator.

## Features

- Live P&L telemetry
- Price/signal check
- Grid-parameter recommendation
- Pay-per-call on Algorand mainnet
- GoPlausible facilitator
- $0.005–$0.05 USDC per call
- x402 discovery at /.well-known/x402
- Catalog available

## Pricing

- $0.005–$0.05 USDC per call

## Deployment

Cloud-hosted on Algorand mainnet via x402 payment rail.
