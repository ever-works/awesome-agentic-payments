## Overview

Second Opinion provides structured second-opinion critique of claims, plans, or draft outputs for AI agents.

## Features

- Critique across five lenses (correctness, risk, completeness, security, assumptions)
- Every issue ships a concrete suggestion and matched evidence span
- Model-backed (Claude)
- Heuristic engine as zero-cost fallback so a call never hard-fails after payment settles
- Free rate-limited preview at GET/POST /sample

## Pricing

- $0.01 USDC per call on Base mainnet (eip155:8453)
- No API keys, no signup

## Deployment

Cloud API
