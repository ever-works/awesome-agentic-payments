## Overview

Universal Commerce Protocol (UCP) is a vendor-neutral commerce protocol for agentic commerce. It is sponsored by the Tech Standards Council and is currently in draft status.

## Features

- Cart, checkout, order, catalog, refunds, and disputes
- Discovery via `/.well-known/ucp` business profile
- Payment authorization: external (any rail)
- Signed requests: RFC 9421 per spec
- Discovery: `/.well-known/ucp` (business profile)
- On-the-wire `version` is a YYYY-MM-DD date

## Specification

- Spec repo: https://github.com/Universal-Commerce-Protocol/ucp
- Pinned version: active draft (date-versioned, e.g. `2026-05-18`)
- Stability: draft with active deployments

## Pricing

Open source specification. Implementation-dependent pricing for SDKs and tooling.
