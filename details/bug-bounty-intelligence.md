## Overview

Bug Bounty Intelligence is an AI-powered smart contract security scanner for AI agents.

## Features

- Trained on 27,681 real accepted findings from Sherlock and Code4rena audit competitions
- Submit a public GitHub repo
- Receive a ranked vulnerability report within 24h
- $5 USDC on Base via x402 autopay
- Free tool: `list_vulnerability_patterns` returns acceptance rates per vulnerability pattern

## Integrations

- MCP: https://github.com/holistis/bug-bounty-intelligence-mcp
- OpenAPI: https://wazir-x402.duckdns.org/openapi.json
- llms.txt: https://wazir-x402.duckdns.org/llms.txt
