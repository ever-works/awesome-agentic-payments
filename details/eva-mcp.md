## Overview

Eva MCP is an autonomous research desk for crypto, DeFi and global markets from the Everything.inc ecosystem.

## Features

- One paid `ask` call runs a multi-step AI agent
- Writes and runs code over live market data
- Data: prices, TVL, open interest, funding rates, liquidations, order-book depth, on-chain flows, news and sentiment
- Returns a plain-text answer
- $0.01 USDC per call on Arbitrum One or Base
- x402 v1 and v2 support
- No API keys

## Pricing

- $0.01 USDC per call on Arbitrum One or Base
- No API keys required

## Deployment

Cloud-hosted MCP server.
