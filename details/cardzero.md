## Overview

CardZero is a payment wallet built for AI agents on Base L2. Each agent receives an ERC-4337 smart contract wallet with owner-controlled spending rules, including per-transaction limits, daily caps, whitelist controls, and freeze functionality. x402 buyer support is available via POST /v1/x402/pay.

## Features

- ERC-4337 smart contract wallet per agent
- Owner-controlled spending rules
- Per-transaction limits
- Daily spending caps
- Whitelist controls
- Freeze/unfreeze capability
- x402 buyer support via POST /v1/x402/pay
- Built on Base L2
