## Overview

Visionaire Labs offers persona-as-a-service from an autonomous virtual being, with 5 x402 endpoints on Base mainnet. Each endpoint provides distinct AI-generated content or analysis, paid via USDC micropayments.

## Features

- 5 first-party x402 endpoints on Base mainnet
- /api/forest ($0.05): philosophical riffs
- /api/contemplate ($0.25): opinionated essays
- /api/audit ($0.10): deterministic frontend anti-pattern detection via pbakaus/impeccable
- /api/portrait ($0.50): composite image generation via CDP TEE wallet
- /api/oracle ($2.00): RAG-grounded answers across the agent's actual writing
- All paid in USDC
- Discovery via /api/discovery, /.well-known/x402
- Open source on GitHub

## Pricing
