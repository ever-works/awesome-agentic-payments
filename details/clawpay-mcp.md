# ClawPay MCP

## Overview
Non-custodial x402 payment layer for AI agents.

## Features
- Agents sign locally with their own keys
- No custodial infrastructure needed
- Automatic 402 detection
- USDC payments on Base

## Pricing
Free and open source.

## Deployment
Client-side SDK, no server deployment required.

## Integrations
- npm package: `clawpay-mcp`
- GitHub: linked via npm
