## Overview

Secant Agent Research Pack provides MCP-first paid web research for autonomous agents, including search, page extraction, normalized JSON, citations, and diff monitoring over x402 with Base USDC.

## Features

- Web search for autonomous agents
- Page extraction
- Normalized JSON output
- Citations
- Diff monitoring
- x402 payment integration with Base USDC
- Codex audit endpoint

## Pricing

- Web research endpoints: $0.001–$0.012 per call
- Codex audit: $0.25 per endpoint

## Deployment

Cloud-hosted API service.

## Integrations

- Base network
- USDC
- x402 payment protocol
- MCP (Model Context Protocol)
