## Overview

SafeAgent Execution Guard is an exactly-once execution guard for AI agents that prevents duplicate payments, emails, and trades when agents retry.

## Features

- Prevents duplicate payments, emails, and trades on agent retry
- Two-phase PENDING → COMMITTED claim
- Crash-safe receipts
- Audit endpoint and audit trail by agent wallet
- Layer 2 in the DashClaw × SafeAgent × Mycelium Trails execution stack
- $0.001 USDC per claim on Base
- Indexed on Bazaar and agentic.market
