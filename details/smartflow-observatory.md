## Overview

SmartFlow Observatory is a public observatory for the x402 endpoint network on Base.

## Features

- Canary probes
- Settlement tracing
- Weekly Atlas drill-downs
- 22,251 endpoints catalogued

## Integrations

- Companion to the Mapper API (https://api.smartflowproai.com)
- Companion to Weekly Intel (https://smartflowproai.substack.com)

## Pricing

Free public observatory.
