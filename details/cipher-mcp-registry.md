## Overview

cipher-mcp-registry is an x402-gated search interface for the Official Model Context Protocol (MCP) Registry.

## Features

- Keyword search across MCP servers
- Returns top 10 matching servers
- Includes name, description, version, repo, and remote endpoints
- x402-gated access

## Pricing

$0.005 USDC/Base per call.

## Deployment

Cloud-hosted on Vercel.
