## Overview

Find Domain is a domain research API for AI agents. It generates domain candidates from keywords and checks availability via DNS estimate or registry lookup, settled via USDC on Base.

## Features

- Domain research API for AI agents
- Generates candidates from keywords
- Stemming, IDN normalization
- Geo/registrar filtering
- Availability check via DNS estimate or registry lookup
- $0.002–$0.01 USDC per query on Base
- skill.md available

## Pricing

- $0.002–$0.01 USDC per query on Base

Cloud-hosted at finddomain.io
