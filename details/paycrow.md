## Overview

PayCrow is an escrow protection service for autonomous agent payments with on-chain trust scoring.

## Features

- Escrow protection for autonomous agent payments
- Trust scoring from 4 on-chain sources
- USDC escrow with dispute resolution on Base
- 10 MCP tools
- safe_pay: trust-informed smart escrow
- trust_gate: go/no-go decision before payment
- Available on npm as paycrow
