## Overview

DripMetrics provides crypto market microstructure and options metrics for AI agents via x402 v2 with Bazaar discovery on every 402.

## Metrics

- VPIN
- Kyle's lambda
- Roll spread
- Order-flow imbalance
- BTC options (GEX, expected move, variance risk premium)
- Polymarket
- Hyperliquid
- On-chain activity
- AI-written BTC market summary

## Deployment

Cloud-based on Base via the Coinbase CDP facilitator.

## Pricing

$0.05–$0.25 USDC per call. No API keys, no signup required.
