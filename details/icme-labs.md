## Overview

ICME Labs provides formal verification for AI agent actions using the ARc paper approach.

## Features

- Natural language policies compile to SMT-LIB formal logic
- Checked by an SMT solver — SAT = allowed, UNSAT = blocked
- Wrapped in zero knowledge proofs for sub-1s verification
- Private policies
- Cryptographic audit trails per decision
- 99%+ soundness under adversarial pressure
