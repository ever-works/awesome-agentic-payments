## Overview

AskClaude MCP is an MCP server for pay-per-query Claude AI access via x402 payments.

## Features

- 9 x402 endpoints
- Haiku/Sonnet/Opus chat
- Streaming
- Summarization
- Code review
- Translation
- Sentiment analysis
- Crypto analysis
- Pricing: $0.01–$0.10 USDC on Base
- Usage: `npx askclaude-mcp`

## Pricing

$0.01–$0.10 USDC per query on Base.
