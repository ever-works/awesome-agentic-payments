## Overview

DevDrops provides 22 pay-per-query data APIs for AI agents via x402 USDC micropayments on Base.

## Data Categories

- Prediction markets (Polymarket + Manifold)
- Property intelligence
- Sports odds
- Regulatory filings
- FX rates
- Weather
- IP geolocation
- Academic papers
- Document summarisation (Claude)

## Deployment

Cloud-based on Base mainnet via x402 USDC.

## Pricing

$0.001–$0.10 USDC per query. No API keys or subscriptions required.
