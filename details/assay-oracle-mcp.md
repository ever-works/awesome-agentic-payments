## Overview

assay-oracle-mcp is an MCP server for the Assay quality oracle, enabling AI agents to verify an x402 service's paid-probe quality tier before making a payment.

## Features

- check_service: Verify a service's quality tier
- get_score: Retrieve quality score for a service
- top_services: Discover top-rated services
- No API key required
- Install via: `claude mcp add assay -- npx -y assay-oracle-mcp`

## Pricing

Open source, free to use.
