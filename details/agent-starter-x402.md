## Overview

agent-starter-x402 is an open-source starter repository for quickly building AI agents that make x402 payments. It is designed to get a crypto-monitoring agent up and running in about 10 minutes.

## Features

- Minimal starter template for x402-paying agents
- Crypto-monitoring agent example
- Free preview tier available
- Pay-per-call settlement on Base
- x402 payment integration

## Pricing

Free and open-source; pay-per-call usage costs apply when deployed.
