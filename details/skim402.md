## Overview

Skim is an x402-native clean reader designed for AI agents. It converts web pages into agent-ready Markdown with structured metadata, enabling agents to consume web content without signup, API keys, or accounts.

## Features

- POST a URL, get agent-ready Markdown plus structured metadata
- Returns title, byline, site, publish date, and language
- Response in milliseconds
- No signup, no API keys, no accounts required
- Structured extraction via /api/v2/extract endpoint
- x402 micropayment native
- MCP server available via npm (skim-mcp)

## Pricing

- $0.002 USDC per call on Base mainnet
- No subscriptions required
