## Overview

loop-mcp is an L402-native Bitcoin/Lightning MCP server for AI agents, providing pay-per-call Bitcoin and Lightning tools.

## Features

- 5 pay-per-call MCP tools
- BTC price
- Fee send-decision (SEND_NOW/WAIT/URGENT_ONLY)
- Lightning Address → BOLT11
- TX decoder
- Optimal send window
- Pricing: 10–25 sats/call
- No API keys
- Live: https://mcp.loopxxi.com/mcp

## Pricing

10–25 sats per call.
