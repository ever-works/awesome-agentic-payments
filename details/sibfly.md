## Overview

SibFly provides measured ground-motion (subsidence & uplift) data for US addresses from NASA OPERA Sentinel-1 InSAR.

## Features

- Measured ground-motion data (subsidence & uplift) in mm/year
- From NASA OPERA Sentinel-1 InSAR
- For AI agents assessing property, infrastructure, and climate risk
- One report per call
- 402 responses carry the x402 `accepts` block
- `X-PAYMENT` settles and serves in one round trip
- Honest prepaid-credit billing, no signup wall
- One-call self-registration at `POST /api/v1/autonomous/register`
- Hosted MCP server (9 tools), OpenAPI, and llms.txt
