## Overview

Viridis Agent Fleet provides five deterministic carbon and compliance tools payable per call via x402 USDC on Base.

## Features

- Quantity takeoff
- GHG inventory
- CSRD/IFRS S2 disclosure
- Clean-energy tax credits
- Regulatory scanning
- x402 USDC payment on Base
- Free dry-run quickstart
- Open-source five-route demo client

## Pricing

Pay-per-call via x402 USDC on Base. Specific pricing not stated on the source page.

## Deployment

Cloud-hosted API service.

## Integrations

- Base network
- USDC
- x402 payment protocol
- MCP (Model Context Protocol)
