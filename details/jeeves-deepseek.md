## Overview

Jeeves-DeepSeek is a pay-per-call DeepSeek chat completions API accessed via x402 micropayments on Base mainnet.

## Features

- OpenAI-compatible chat completions endpoint
- DeepSeek model access via x402 micropayments
- No signup required
- No API keys required
- Pay-per-call pricing model

## Pricing

$0.01 USDC per request on Base mainnet.

## Integrations

- Endpoint: `/v1/chat/completions`
- x402 payment protocol on Base (eip155:8453)
