## Overview

Spraay Gateway is a multi-chain batch payment protocol and x402 gateway. It offers 76+ paid endpoints across 16 categories and 13 chains.

## Features

- Multi-chain batch payment protocol
- x402 gateway
- 76+ paid endpoints across 16 categories and 13 chains
- Batch payments, payroll, token swaps, bridge, escrow
- AI inference (43+ models)
- Robot Task Protocol (RTP)
- Agent wallets
- MCP server with 60+ tools available

## Pricing

USDC micropayments via x402.

## Deployment

Cloud gateway at gateway.spraay.app
