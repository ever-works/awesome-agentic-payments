## Overview

Polymarket Liquidity API provides real-time liquidity data for Polymarket prediction markets. It offers order book depth, spread analysis, and market efficiency scoring via x402 micropayments on Base.

## Features

- Real-time Polymarket prediction market liquidity data
- Order book depth analysis
- Spread analysis
- Market efficiency scoring
- x402 micropayments
- $0.005 USDC on Base
- Open source on GitHub
- llms.txt available

## Pricing

- $0.005 USDC per call on Base
