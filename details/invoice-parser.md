## Overview

Invoice Parser is a structured invoice data extraction service for finance automation agents. It extracts key invoice fields from PDF and image documents and returns clean JSON for accounting system integration.

## Features

- Vendor name extraction
- Total amount extraction
- Line item extraction
- Date extraction
- Tax amount extraction
- Payment details extraction
- Clean JSON output
- PDF and image invoice support
- No API keys required
- No signup required
- x402 USDC payment on Base

## Pricing

- $0.10 USDC per invoice parse

## Deployment

Cloud-hosted (Google Cloud Run)
