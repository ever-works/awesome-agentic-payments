## Overview

Hermes Plant offers deterministic per-record validation and finance math for AI agents, ensuring same input always produces the same answer with per-rule evidence.

## Features

- Email/contact validation and normalization (loop a whole list; MCP batch tool included)
- Wallet AML screening
- x402 payment-policy preflight
- DCF, IRR/XIRR calculations
- LP/GP waterfalls
- Black-Scholes Greeks
- Bond analytics
- Deterministic: same input, same answer
- Per-rule evidence, no data feed
