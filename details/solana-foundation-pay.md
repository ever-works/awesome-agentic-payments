## Overview

Solana Foundation Pay is a local payment layer for handling x402 payment challenges with wallet-authorized stablecoin signing. It includes x402/MPP CLI and MCP tools.

## Key Features

- Local payment layer for x402 payment challenges
- Wallet-authorized stablecoin signing
- x402/MPP CLI tools
- MCP (Model Context Protocol) integration
- Solana network support

## Deployment

Self-hostable from GitHub repository.
