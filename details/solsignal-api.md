## Overview

SolSignal API is a Solana token safety scanner that aggregates multiple data sources into a single safety verdict for AI agents.

## Pricing

- 10 free scans per day
- $0.01 USDC per call on Solana after free tier

## Features

- Aggregates DexScreener, RugCheck, GoPlus, and Jupiter simulation
- Returns SAFE/CAUTION/AVOID/RUG verdict
- Response time under 2 seconds

## Integrations

- USDC on Solana for micropayments
- x402 payment enforcement
