## Overview

x402-api is a pay-per-call DeFi & crypto data API with USDC micropayments on Base.

## Features

- 8 endpoints: price feeds, whale tracking, gas tracker, DEX quotes, token scanner, yield scanner, funding rates, wallet profiler
- USDC micropayments on Base
- ERC-8004 Agent #18763

## Pricing

Pay-per-call USDC micropayments on Base mainnet.
