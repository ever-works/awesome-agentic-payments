## Overview

paysh-agent-recipes is an open-source collection of copy-pasteable scripts for AI agents that need to make payments per request via pay.sh. No API keys are required; each recipe is a standalone script with a dry-run demo mode.

## Features

- Copy-pasteable payment recipes for AI agents
- Pay-per-request model via pay.sh
- No API keys required
- Each recipe is a single script
- Dry-run demo mode included
- Wallet whale-watchers with SMS alerts
- Realtime block-scanning capability
- Pluggable sinks: Telegram, webhook, websocket, stdout
- Backed by Solana Foundation and Google Cloud

## Pricing

Free and open-source; per-request payment costs apply when recipes are executed.
