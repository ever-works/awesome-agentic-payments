# Voidly Pay

## Overview
USDC-backed agent-to-agent payment rail on Base mainnet.

## Features
- Source-verified vault
- Public proof of reserves
- Facilitator-signed quotes (anti-MitM)
- Ed25519-signed envelopes
- 28-tool MCP server
- TypeScript + Python SDKs
- Express/Hono/Flask/FastAPI middleware
- Live paid endpoints: forecast-pro, claim-verify-pro, incident-summary-pro
