## Overview

x402check is a pre-payment reconnaissance tool for x402 endpoints. It reads the /.well-known/x402 manifest (network, asset, price, routes) and checks the payment recipient on-chain to verify whether the wallet is active and funded or a dead drop.

## Features

- Reads /.well-known/x402 manifest (network, asset, price, routes)
- On-chain wallet verification for payment recipients
- Read-only, no keys required
- Uses public block explorers only
- Pure Python standard library
