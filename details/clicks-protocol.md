## Overview

Clicks Protocol is an autonomous yield layer for AI agents on Base blockchain.

## Features

- Auto-splits USDC deposits 80/20: 80% liquid, 20% earning
- Yield via Morpho (~13% APY) or Aave V3
- No lockup
- 2% fee on yield only
- SDK available
- MCP Server (9 tools)
- HTTP API

## Pricing

2% fee on yield only.
