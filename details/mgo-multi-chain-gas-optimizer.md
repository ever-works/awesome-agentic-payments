## Overview

MGO — Multi-chain Gas Optimizer compares real-time gas prices across EVM chains.

## Features

- Compares real-time gas prices across EVM chains
- Returns cheapest-chain recommendation
- Two tiers on Base via Coinbase CDP facilitator
- Basic: $0.001 (4 chains — ETH, Base, Arbitrum, Optimism)
- Premium: $0.002 (9 chains — adds BNB, Polygon, Avalanche, zkSync, Hyperliquid)
- x402 v2 with Bazaar discovery extension
- Free demo, no API keys

## Pricing

- $0.001–$0.002 USDC per call
