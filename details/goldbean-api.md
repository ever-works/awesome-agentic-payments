## Overview

GoldBean is an x402 Micropaid API Marketplace offering crypto and DeFi data endpoints for AI agents. It provides real-time market data without requiring API keys, with payments handled via x402 USDC micropayments on Base.

## Features

- 7 paid crypto/DeFi endpoints: BTC price, gas forecast, market sentiment, DeFi insights, network health, MEV tracking, token risk
- Pricing: $0.01-$0.05 USDC per call on Base
- No API keys needed
- x402 Bazaar manifest at /.well-known/x402-bazaar
- Open source repository on GitHub
