## Overview

SFtunes offers hand-made human mixtapes with per-track liner notes, curated by real friends, as a paid catalog for AI agents.

## Features

- Hand-made human mixtapes with per-track liner notes
- Curated by real friends
- Paid catalog for AI agents
- 80% of every payment goes to the human who made the tape

## Pricing

- $0.01 USDC per tape via x402 on Base (CDP facilitator, Bazaar discovery on every 402)
- No API keys, no signup

## Deployment

Cloud API
