## Overview

OpSpawn Bazaar is a suite of seven AI-powered x402 microservices for AI agents. It covers screenshot capture, sentiment analysis, summarization, translation, fact-checking, and entity extraction on the Base network.

## Features

- Seven AI-powered x402 microservices
- Screenshot capture
- Sentiment analysis
- Summarization
- Translation
- Fact-checking
- Entity extraction
- Base network

## Pricing

- Pay-per-use via x402 USDC

## Deployment

Cloud-hosted at a2a.opspawn.com

## Integrations

- x402 payment protocol
- Base mainnet USDC
