## Overview

Sanctions Screening screens people, companies, and crypto wallet addresses against sanctions lists.

## Features

- Screen against OFAC SDN list (US Treasury) and UN Security Council Consolidated List
- Matches with source list, sanction programs, alias matched, and match type (exact/token/address)
- List-freshness metadata
- Covers 20k+ sanctioned entities and 400+ sanctioned wallet addresses across chains (ETH, BTC, TRX, XMR...)
- Data: US Treasury + UN (public government data)
