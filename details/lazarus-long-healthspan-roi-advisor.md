## Overview

Lazarus Long Healthspan ROI Advisor ranks evidence-based longevity interventions by ROI for older adults.

## Features

- POST a user profile (age cohort, health concerns, time, budget)
- Receive top 5 interventions with evidence grades, expected benefits, and effort levels

## Pricing

- $0.05 USDC per call on Base mainnet via Coinbase CDP facilitator
- No API keys, no signup

## Deployment

Cloud API
