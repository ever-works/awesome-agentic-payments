## Overview

BlockRun is an AI Gateway and Service Directory that indexes 600+ x402 services with trust scores. It provides access to 31+ AI models via pay-per-use USDC payments, enabling AI agents to discover and pay for services.

## Features

- AI Gateway + Service Directory
- 600+ x402 services indexed
- Trust scores for services
- 31+ AI models via pay-per-use USDC
- Service discovery and routing

## Pricing

- Pay-per-use via x402 USDC

## Deployment

Cloud-hosted at blockrun.ai

## Integrations

- x402 payment protocol
- USDC
