## Overview

Vindex is a pay-per-call vehicle-data API for AI agents. It provides VIN decode with warranty terms, recalls, reliability data, and purchase-cost estimates for US and Canadian vehicles, sourced from NHTSA and Transport Canada.

## Features

- Pay-per-call vehicle-data API for agents
- VIN decode with original factory warranty terms
- Recalls
- Known-issues/reliability data
- Purchase-cost estimates (US and Canada)
- Sourced from NHTSA and Transport Canada
- $0.01/call USDC
- Settling on Base and Solana
- MCP server on npm (vindex-mcp)

## Pricing

- $0.01 USDC per call

## Deployment

Cloud-hosted at api.vindexapi.dev

## Integrations

- x402 payment protocol
- Base and Solana USDC
- MCP server via vindex-mcp npm package
