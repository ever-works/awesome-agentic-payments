## Overview

OnchainAI is a crypto tool directory MCP (Model Context Protocol) server designed for AI agents. It provides tool discovery, trust scoring, and x402 pay-per-call endpoints for accessing crypto tooling.

## Features

- Search crypto tools for agents
- Trust/install-risk assessment
- Tool comparison
- x402 endpoint probes
- Verified picks
- Gap audits
- Remote `POST /mcp` tools/call with x402 pay-per-call
- No third-party fund custody
- Endpoint: https://www.onchain-ai.xyz/mcp

## Pricing

~$0.1 USDT0 per call on X Layer (when OKX gate is active); CDP/Base premium routes also paid. Website browsing may be free.

## Deployment

Remote MCP endpoint (cloud-hosted).
