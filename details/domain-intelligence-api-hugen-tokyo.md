## Overview

Domain Intelligence API provides comprehensive domain analysis through 8 endpoints. It covers WHOIS, DNS, SSL/TLS, technology detection, security headers, and more, settled via USDC on Base.

## Features

- 8-endpoint domain analysis API
- WHOIS lookup
- DNS with 3-resolver parallel resolution
- SSL/TLS grading
- Wappalyzer tech detection
- Security headers analysis
- CT log subdomains
- Redirect chain analysis
- Full domain reports
- $0.001-$0.02 USDC on Base
- llms.txt available
