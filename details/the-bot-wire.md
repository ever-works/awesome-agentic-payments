## Overview

The Bot Wire provides real-time news wire for AI agents via x402 v2 on Base.

## Features

- 40 curated sources (markets, crypto, tech, world, business, energy)
- Refreshed every 5 minutes
- Full-text searched in ~1ms with per-article freshness timestamps
- GET /news (ranked search with summaries)
- GET /headlines (by category)

## Deployment

Cloud-based on Base mainnet via x402 v2.

## Pricing

$0.005 USDC per call. Free preview tier. No API keys, no signup required.
