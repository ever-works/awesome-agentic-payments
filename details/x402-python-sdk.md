## Overview

Official Python SDK for the x402 protocol from the x402 Foundation. Provides client, server, facilitator, and MCP helpers for integrating x402 payments into Python applications.

## Key Features

- Official Python client for x402 payments
- Server-side payment verification helpers
- Facilitator integration utilities
- MCP (Model Context Protocol) helpers
- Available as PyPI package
- Part of the x402 Foundation monorepo

## Deployment

Published as PyPI package, can be self-hosted.
