## Overview

n0brains provides crypto intelligence with auditable per-signal-type win-rates, accessible via 6 pay-per-call x402 endpoints on Base.

## Features

- Live auditable per-signal-type win-rate at /proof
- Forward returns vs BTC with 95% CI
- Underperforming signal types demoted in the open
- 6 pay-per-call x402 endpoints on Base:
  - Signals
  - Rotation
  - Correlation
  - DEX liquidation map
  - S/R levels
  - Macro
- $0.005/signal USDC
- No account required
- MCP server with 23 tools
- pip install n0brains-cli
- x402 discovery at api.n0brains.com/.well-known/x402.json
