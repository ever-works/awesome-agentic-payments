## Overview

SEODesignLab SEO Intelligence is a full-stack SEO intelligence API built for AI agents. It provides actionable SEO data including content briefs, keyword research, SERP analysis, backlink profiles, and on-page audits — delivered as intelligence agents can use to write ranking content.

## Features

- POP content briefs
- Keyword research
- SERP analysis
- Backlink profiles
- On-page audits
- MCP server for Claude, Cursor, and Windsurf
- USDC on Base via x402
- No API keys required
- No signup required
- npx @seodesignlab/mcp-server installation
