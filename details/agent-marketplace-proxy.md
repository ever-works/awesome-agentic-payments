## Overview

agent-marketplace-proxy is an x402-gated Google SERP API that proxies DataForSEO search results. It serves as a reference implementation for wrapping commodity REST APIs with x402-express middleware.

## Features

- POST /search endpoint
- Returns top organic results from DataForSEO
- No API key, no signup, no credit card required
- ~80 lines reference implementation
- x402-express middleware example
