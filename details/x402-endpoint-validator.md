## Overview

x402-endpoint-validator is a GitHub Action that validates x402 endpoints in CI pipelines.

## Features

- Validates 402 challenge shape
- Validates EIP-712 typed data
- Validates settlement path
- Validates well-known schema
- Drop-in YAML configuration
- MIT licensed

## Pricing

Open source, free to use.

## Deployment

GitHub Action (CI/CD)
