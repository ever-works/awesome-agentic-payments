## Overview

Rug Scanner is an on-chain token risk analysis API that performs multiple parallel checks to assess token risk, accessible via x402 micropayments on Base.

## Features

- 7 parallel risk checks: bytecode, holders, liquidity, deployer, trading, verification, market
- Deterministic scoring
- x402 pay-per-scan

## Pricing

$0.05 USDC per scan via x402 on Base.
