## Overview

TextAI API is a pay-per-use text AI API offering summarize, extract keywords, and translate functions with USDC micropayments on Solana. It uses a credit-based model with 100 free credits, then pay-per-call.

## Features

- Text summarization
- Keyword extraction
- Translation
- USDC micropayments on Solana
- Credit-based: 100 free credits, then pay-per-call
- No subscription
- No KYC
- x402 protocol support on roadmap

## Pricing

- 100 free credits
- $0.001–$0.015 per call after free credits
- USDC on Solana
