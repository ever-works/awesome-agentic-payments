## Overview

JubJub is a canonical ownership layer for media. Users can publish to all major media platforms via MCP, with on-chain ownership records on Base, cross-platform analytics, and automatic royalty and revenue splits.

## Features

- Canonical ownership layer for media
- Publish to all major media platforms via MCP
- On-chain ownership records on Base
- Cross-platform analytics
- Automatic royalty and revenue splits
- USDC on Base

## Pricing

USDC on Base via x402 micropayments.

MCP Server: https://api.jubjubapp.com/v2/mcp
