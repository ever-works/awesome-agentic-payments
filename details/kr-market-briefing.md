## Overview

kr-market-briefing provides Korea crypto market intelligence, synthesizing kimchi premium, KR exchange prices, Korean sentiment, and global macro into decision-ready briefings.

## Features

- Kimchi premium tracking
- KR exchange prices
- Korean sentiment analysis
- Global macro synthesis
- Decision-ready briefings
- x402 payment on Base

## Pricing

- $0.35 USDC per call on Base

## Deployment

Cloud-hosted API service.

## Integrations

- Base network
- USDC
- x402 payment protocol
