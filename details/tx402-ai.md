## Overview

tx402.ai is an agent-native LLM inference gateway that provides access to 20+ EU-hosted models via x402 USDC micropayments on Base.

## Pricing

- x402 USDC micropayments on Base (pricing varies by model)

## Features

- 20+ EU-hosted models (DeepSeek, Qwen, Llama, GLM, Mixtral)
- OpenAI-compatible API
- SSE streaming
- GDPR-compliant
- Zero data retention
- No API keys; wallet is auth

## Integrations

- USDC on Base for micropayments
- x402 payment enforcement
