## Overview

IPIntel.ai provides machine-payable IP threat intelligence lookup via x402 on Base blockchain.

## Features

- JSON risk scoring for IP addresses
- ASN/ISP context
- Hosting/proxy/Tor indicators
- Bot signals detection
- Infrastructure metadata
- No account or API key required
- OpenAPI specification available

## Pricing

$0.001 USDC per IP lookup on Base mainnet.

## Integrations

- Endpoint: `https://api.ipintel.ai/x402/?ip={ip}`
- OpenAPI: `https://api.ipintel.ai/openapi.json`
- x402 payment protocol on Base (eip155:8453)
