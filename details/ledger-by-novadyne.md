## Overview

Ledger by Novadyne provides x402-native double-entry bookkeeping for AI agents via an API and MCP server.

## Features

- x402-native double-entry bookkeeping API
- MCP server for AI agents
- Pay per call in USDC on Base
- No signup or API key required
- $0.002/read, $0.01/write
- Sum-to-zero double-entry invariant
- Ed25519-signed attestation at /.well-known/attestation
- Usage: `pip install ledger-mcp`

## Pricing

$0.002 per read, $0.01 per write (USDC on Base).

## Deployment

MCP server + API (cloud).
