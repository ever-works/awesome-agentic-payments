## Overview

SolSigs ProofGuard is a post-payment trust and refund-evidence layer for AI agents using x402 endpoints on Solana.

## Features

- /proofguard/evaluate returns decision flags, receipt fields, trust scoring, and evidence links
- Designed for Solana x402 calls
- Post-payment trust layer
- Refund evidence collection

## Pricing

- $0.003 USDC per call on Solana

## Deployment

Cloud-hosted, settlement via Solana mainnet via x402 payment rail.
