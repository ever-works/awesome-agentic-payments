## Overview

cipher-gas-oracle is an x402-gated multi-chain gas price oracle providing live gas data across multiple EVM networks.

## Features

- Live slow/standard/fast gwei pricing
- Supported chains: Base, Ethereum, Arbitrum, Optimism
- Returns gasPrice, maxPriorityFee, baseFee, typical transfer cost
- Single-call multi-chain data
- x402-gated access

## Pricing

$0.005 USDC/Base per call.

## Deployment

Cloud-hosted on Vercel.
