## Overview

EconDash provides global macroeconomic data API for AI agents via x402 USDC micropayments on Base.

## Data

- 753 indicators across 298 countries (World Bank, FRED, OECD)
- 15 x402-protected endpoints for GDP, inflation, employment, trade, country profiles, rankings, and metadata

## Deployment

Cloud-based on Base mainnet via x402 USDC.

## Pricing

$0.02 USDC/call on Base. Also supports MPP (Tempo + Solana).
