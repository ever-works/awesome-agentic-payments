# AgentLayer

## Overview
Open-source, local-first wallet for AI agents.

## Features
- x402 payments
- DeFi tools for Base, Solana, and Ethereum
- Swaps
- Lending
- Borrowing
- Keys stored in macOS Keychain
- Local-first

## Pricing
Free and open source.

## Deployment
Local-first wallet, runs on user's machine.
