## Overview

OpenClaw Discovery Index is an x402-gated search engine that indexes 13,000+ x402-enabled APIs from CDP Bazaar. Agents can search by capability, category, and network without needing an account.

## Features

- x402-gated search engine
- 13,000+ x402-enabled APIs indexed from CDP Bazaar
- Search by capability, category, and network
- $0.01 USDC per search on Base mainnet (eip155:8453)
- No account needed

## Pricing

- $0.01 USDC per search on Base mainnet

## Deployment

Cloud-hosted at x402search.xyz

- x402 payment protocol
