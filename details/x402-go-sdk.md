## Overview

Official Go SDK for the x402 protocol from the x402 Foundation. Provides client, server, facilitator, and MCP package for integrating x402 payments into Go applications.

## Key Features

- Official Go client for x402 payments
- Server-side payment verification helpers
- Facilitator integration utilities
- MCP (Model Context Protocol) package
- Part of the x402 Foundation monorepo

## Deployment

Published as Go module, can be self-hosted.
