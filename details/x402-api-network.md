## Overview

x402 API Network is a collection of 16 micropayment-powered APIs for AI agents. It covers email verification, domain health, web scraping, AI content generation, DNS, WHOIS, SSL checks, and more, with MCP server and Bazaar discovery support.

## Features

- 16 micropayment-powered APIs for AI agents
- Email verification, domain health, web scraping
- AI content generation (Llama 3.3 70B)
- DNS, WHOIS, SSL check
- MCP server included
- Bazaar discovery
- .well-known/x402 manifest
- Open source on GitHub

## Pricing

- Pay-per-call via x402 USDC
