## Overview

Cook County / Chicago Property Data MCP is a hosted remote MCP server providing access to property records for Cook County and Chicago, Illinois.

## Features

- Parcels data
- Recorded sales
- Building permits
- Tax assessments
- Comparable sales
- Search by address or PIN
- Pay-per-call via x402
- USDC on Base or Solana
- Endpoint: api.ingest0r.com/mcp

## Pricing

Pay-per-call via x402 (USDC on Base/Solana).

## Deployment

Hosted remote MCP (cloud).
