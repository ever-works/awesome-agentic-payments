## Overview

x402 Vending Machine is a Base mainnet USDC bundler hub for AI agents supporting x402 V2 and Coinbase CDP.

## Tools

~19 pay-per-call tools including multi-step packs (`bundle-infra`, `bundle-outbound`, `domain-intel`), DNS/TLS/WHOIS/HTTP utilities, email MX, FX, IP geo, CoinGecko spots, QR, page text extract, Base balances, and Kronos BTC/ETH candle research forecasts.

## Deployment

Cloud-based on Base mainnet via x402 V2 + Coinbase CDP.

## Pricing

Pay-per-call USDC micropayments on Base. Live data only; fail-closed (no settle on handler errors).
