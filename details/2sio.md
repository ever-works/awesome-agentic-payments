## Overview

2s.io is a pay-per-call JSON API for AI agents with 35 endpoints spanning geolocation, web tools, image processing, barcodes, DNS/WHOIS, weather, climate, natural disaster data, reference content, legal/regulatory data, and demographics.

## Features

- 35 endpoints across multiple categories
- Geo/IP lookups
- Web extract, summarize, translate, screenshot
- Image compress and describe
- Barcodes: QR, Aztec, DataMatrix, PDF417
- DNS + WHOIS
- EVM gas oracle
- US weather (NWS)
- Climate stations, tides, sunrise (NOAA)
- Live quakes and wildfires (USGS)
- Wikipedia
- Papers: arXiv, PubMed, Semantic Scholar
- Patents
- Federal court opinions, Federal Register, OFAC sanctions
- US Census demographics
- Airport registry
- Sub-cent to $0.03 USDC on Base via Coinbase facilitator
- Bearer-account flow in preview
- x402 discovery at /.well-known/x402
- OpenAPI specification
- llms.txt

## Pricing

- Sub-cent to $0.03 USDC per call on Base

## Deployment

Cloud-hosted on Base mainnet via x402 payment rail.
