## Overview

MoonMaker API is an AI-native crypto data API with x402 pay-per-call access, offering 11 endpoints for signals, market context, DeFi regime, institutions, ETF flows, DeFi yields, and DEX alpha.

- 11 endpoints: signals, market context, DeFi regime, institutions, ETF flows, DeFi yields, DEX alpha
- x402 pay-per-call
- No signup required
