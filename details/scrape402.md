## Overview

## Features

- Web scraping (clean text, markdown, PDF-to-text, LLM structured extract)
- Crypto market data (spot with batch pairs, OHLC candles with backtest ranges, order book, gas oracle)
- FX rates
- Weather (current + historical)
- RSS-to-JSON
- Data utilities
- $0.002-$0.015 USDC on Base via the CDP facilitator
- No API keys, no signup
