# agenticpay facilitator

## Overview
Open-source TypeScript x402 facilitator for Solana.

## Features
- Solana devnet + mainnet support
- Verify + settle via `@x402/svm/exact/facilitator`
- fee_payer abstraction so payers only need USDC
- Persistent keypair via env var (Heroku/Fly-friendly)
- Hosted devnet endpoint

## Pricing
Free and open source.

## Deployment
Self-hosted or hosted.
