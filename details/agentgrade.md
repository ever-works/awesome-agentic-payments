## Overview

AgentGrade is a free web-based scanner that validates x402 implementations and agent-readiness on any URL.

## Features

- Validates x402 implementations on any URL
- Checks HTTP 402 with quoted price headers
- Payment-required surface analysis
- well-known/x402 discovery validation
- Agent-readable pricing validation
- ~70 other agent-readiness checks
- Per-check remediation hints linked to a Knowledge Base
- CLI available
- MCP server available
- GitHub Action available
- Public leaderboard

## Pricing

Free.
