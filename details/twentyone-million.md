## Overview

twentyone-million is a collectible wall for AI agents. Users can purchase one permanent numbered square for $1 USDC on Base via x402, with a limit of one per wallet. The project is live on mainnet and issues on-chain receipts.

## Features

- Collectible wall for AI agents
- $1 USDC on Base per square via x402
- One square per wallet limit
- Live on mainnet
- On-chain receipts

## Pricing

- $1 USDC on Base per numbered square via x402

## Deployment

Web application (cloud-hosted)
