## Overview

Vercel acp-handler is an official ACP handler from Vercel. It implements the Agentic Commerce Protocol in TypeScript for deployment on Vercel's serverless platform.

## Features

- ACP protocol handler
- TypeScript implementation
- Official Vercel project
- Serverless deployment

## Specification

- Type: Handler
- Protocols: ACP
- Language: TypeScript
- Maintainer: Vercel (official)

## Pricing

Open source (MIT license). Vercel platform pricing applies for hosting.

## Deployment

Cloud (Vercel) or self-hosted.
