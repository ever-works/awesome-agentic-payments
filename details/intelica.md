## Overview

Intelica provides competitive intelligence API for autonomous AI agents via x402 USDC micropayments on Base and Solana mainnet.

## Features

- Analyzes any URL or company description
- Returns structured JSON with market positioning, competitors, pain points, and executable Market Score
- 10 context modes: regulatory_compliance, venture_screening, crypto_protocol, sales_enablement, and more
- MCP server at /mcp
- A2A protocol at /message/send

## Deployment

Cloud-based on Base and Solana mainnet via x402.

## Pricing

Standard tier $0.05 USDC, Elite tier $1.00 USDC per call.
