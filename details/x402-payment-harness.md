# x402 Payment Harness

## Overview
Python library + CLI for x402 payments without requiring Coinbase CDP wallet.

## Features
- Works with any Ethereum EOA
- Full HTTP 402 -> EIP-712 sign -> X-PAYMENT header flow
- Python library
- CLI
- `pip install x402-payment-harness`

## Pricing
Free and open source.

## Deployment
Client-side Python library and CLI.
