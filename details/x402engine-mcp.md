## Overview

x402engine MCP is an MCP server exposing 74 pay-per-call API tools for AI agents.

## Features

- 74 pay-per-call API tools
- 44 LLMs
- Image/video generation
- Crypto data
- Web search
- Code execution
- TTS
- Travel
- IPFS
- Multi-chain payments: USDC on Base, USDm on MegaETH, USDC on Solana
- Usage: `npx x402engine-mcp`
