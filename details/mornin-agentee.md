## Overview

mornin-agentee is a daily Tokyo morning briefing API generated by an OpenClaw multi-agent system (researcher + coder + main), accessible via x402 micropayments on Base mainnet.

## Features

- Top 5 Japanese news with URLs
- Weather (today/tomorrow)
- 3 focus proposals
- One-liner summary
- Refreshed daily at 07:30 JST
- Cached output (near-zero marginal cost)

## Pricing

$0.05 USDC per call on Base mainnet.

## Deployment

Cloud-hosted API. Open source at https://github.com/Minnanthu/mornin-agentee
