## Overview

Azimuth is a radio-frequency positioning DePIN for AI agents.

## Features

- Pay-per-call location APIs — estimate position from cellular observations
- Receiver-node registration and status
- USDC on Solana and Base (x402 v2)
- Machine-readable discovery
- Bazaar extension on every route
- No API keys

## Pricing

- $0.001–$0.10 per call
