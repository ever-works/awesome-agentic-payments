## Overview

Registry & Sanctions Data provides KYB and compliance primitives for AI agents, enabling company resolution, sanctions screening, vulnerability checks, and recall data.

## Features

- GLEIF company resolution
- OFAC/EU/UN sanctions screening with ownership-chain traversal
- OSV vulnerability checks
- FDA recalls
- HTTP API and paid MCP server
- Pay-per-call USDC on Base
- No API keys required
