## Overview

ShieldAPI provides security intelligence for AI agents, including breach checks, reputation lookups, URL safety scanning, and prompt injection detection. It uses x402 USDC micropayments on Base with no account or API key required.

## Features

- Password breach checks (900M+ HIBP hashes)
- Email breach lookup
- Domain/IP reputation
- URL safety scanning
- Prompt injection detection
- Skill security analysis
- Pay-per-request via x402 USDC micropayments
- $0.001–$0.02 on Base
- No account, no API key
- Free demo mode on all endpoints
- MCP server available on npm
- CLI available on npm
- Open source on GitHub

## Pricing

- $0.001–$0.02 USDC per request on Base
