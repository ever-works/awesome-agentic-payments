## Overview

x402services provides DeFi data APIs for AI agents on Base blockchain.

## Features

- 8 endpoints: gas oracle, token price oracle, wallet analyzer, token security scanner, ENS resolution (forward + reverse), DEX trade simulation, contract event history
- Bazaar discovery enabled

## Pricing

$0.001–$0.01 USDC per call on Base mainnet (eip155:8453).

## Integrations

- Source: https://github.com/x402services/api
- x402 payment protocol on Base (eip155:8453)
