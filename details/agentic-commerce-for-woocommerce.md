## Overview

xpaysh reference WordPress plugin implementing ACP, UCP, and AP2 protocols for WooCommerce. This is a reference implementation, not a production-hardened first-party path.

## Features

- Protocols: ACP, UCP, AP2
- Rails: x402, cards via PSP
- Type: WordPress plugin (PHP)
- Maintainer: xpaysh (reference implementation)
